ESP & Chams

Configure player, entity, NPC and vehicle visuals. Combine boxes, names, health and armor bars, weapon info and distance with skeletons, snaplines and compact head markers. Fine-tune each feature from its settings button.

Rage & Legit

Rage offers configurable hitboxes, target priorities, hit chance, minimum damage and firing controls. Legit includes FOV, smoothing, recoil control and a triggerbot. Set target filters and assign keyboard or mouse binds to the controls you use.

World & View

Adjust camera FOV, viewmodel FOV and weapon offsets from the View tab. Customize nightmode brightness and tint, visual removals, weapon-drop ESP and bullet tracers.

Radar & Overlays

A matching radar offers square or circular layouts, range rings and configurable markers. The watermark includes an FPS graph, with options for ping, time and server details. Add binds, spectators, staff and session-stat overlays.

Hotkeys, Search & Favorites

Search across the menu and press F while hovering a feature to add it to favorites. Bind keyboard or mouse buttons with always-on, toggle, hold and hold-to-disable modes, then keep active binds visible in an overlay.

An Interface That Fits

Use automatic resolution scaling or adjust the menu scale from 25% to 200%. Scale overlays independently, resize the menu and customize feature colors with RGB, HEX and alpha controls. Fonts are rendered at the selected size for clearer text.

Lua Scripts & Editor

Create and select local Lua scripts, edit with syntax highlighting, and keep per-file drafts with undo and redo. Run client-side Lua or send console commands from the toolbar, with script folders and Lua utilities close at hand.

Language Packs & Profiles

Create, rename, import and export profiles, choose a startup default, and enable auto-save for the active config. Select from 23 JSON language packs; untranslated labels fall back to English. Custom language files can be edited and reloaded from the menu.

Movement & Feedback

Configure bunny hop, air strafe, edge jump, crouch jump and movement extras. Add a speed indicator, velocity graph, custom crosshair, hitmarkers, hit sounds and damage feedback.

Gamemode Tools

Dedicated pages cover TTT, Murder, DarkRP, Prop Hunt and GRust, including role indicators, player information, prop highlighting and resource ESP. Available information depends on the active gamemode and server.

Common Questions

Is Scooby GMOD free?

Yes. GMOD uses a free key. Select Get Free Key for the steps, then continue to the key page.

Which version of Garry's Mod does it use?

Use Garry's Mod on Windows with Steam's x86-64 branch selected under Properties → Game Versions & Betas. Load Scooby while the game is at the main menu. Game updates can affect compatibility; check the product status and support channel if you need help.

How do I open the GMOD cheat after loading?

Use Insert or F2 by default. If the interface does not appear, confirm that Steam has finished installing the x86-64 branch and that you loaded Scooby at the game's main menu. Follow the step-by-step GMOD setup guide before retrying.

Do the same features work in every gamemode?

Available information depends on the active gamemode and server. TTT, Murder, DarkRP, Prop Hunt and GRust have their own tools; use the GMOD feature list to check the settings for your gamemode.

Can I run Lua scripts?

Yes. The editor can run client-side Lua while you are loaded into a game. Select a local script or write a draft, then use Run Lua or Ctrl+Enter. Run Console sends the editor contents to the game console.

Are all 23 language packs fully translated?

No. English is the complete fallback language. Other packs translate part of the interface, and any missing labels remain in English.
