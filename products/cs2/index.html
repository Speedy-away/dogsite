Scooby CS2 is a free menu for Counter-Strike 2 on Windows. Choose Click UI or List UI, configure your visuals and controls, and save your setup in a profile. The menu brings together aim assistance, cosmetic customization, local inventory tools, movement options and world effects.

Browse the full CS2 feature library to search individual features and their settings.

Aim and recoil controls

Configure aim FOV, smoothing, hitboxes, target checks and weapon-specific settings. Recoil compensation has separate vertical and horizontal controls, including a standalone mode.

Triggerbot

Set activation keys, delays, bursts and visibility checks, with flick-fire, prediction and auto-stop options.

ESP and chams

Customize player boxes, health and armor, skeletons, equipment and off-screen arrows. Set separate material styles for enemies, teammates, your own model, arms and weapons.

Skins and loadouts

Choose weapon finishes, knives, gloves and agents. Edit supported wear, pattern seeds, StatTrak counters, name tags, stickers, charms and agent patches.

Local inventory

Browse item categories, manage local items, apply team loadouts and use local case-opening tools.

Custom models

Select installed player and weapon models, configure the first-person view, and restore defaults when needed.

World visuals

View dropped items, grenade paths, timers, bomb information and hit feedback. Customize the skybox, fog, lighting, weather and particle colors.

Movement and camera

Configure bunny hop, edge jump, edge bug, auto strafe, third person and viewmodel adjustments.

Overlays and interface

Set up radar, a quick map, spectator and player lists, performance stats, keybinds and a custom crosshair. Customize themes, fonts, images and saved profiles.

Setup and updates

Start with the CS2 setup guide. Custom models require installed model packs, and some features depend on the current game build. If a game update changes feature availability, check the CS2 update guide.
