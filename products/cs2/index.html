CS2 setup and common questions

Is Scooby CS2 free?

Yes. Select Get Free Key on this page and follow the key instructions. The CS2 feature list describes the available controls and customization options.

How do I equip custom CS2 models?

Open Custom > Library, choose the installed model and target, then select Equip model. Use Repo to find compatible packs in builds that include it. Model swaps apply on your client.

Do inventory items appear in my Steam inventory?

Skin changes, local inventory additions and case-opening results apply to your local setup. They carry no Steam inventory or trading value.

What do I need before loading the CS2 cheat?

Use Counter-Strike 2 on Windows and install the Microsoft Visual C++ runtimes listed in the CS2 requirements guide. It provides the x64 and x86 downloads and links to runtime troubleshooting.

Does loading Scooby restart CS2?

The loader's Load button closes CS2, reopens it and loads Scooby automatically. Manual loading is also available when CS2 is already at the main menu. Follow the CS2 loading guide for the two flows.

Why does the interface open but features stop working after a CS2 update?

A new game build can require a matching Scooby update. Check the CS2 update guide and the linked support channel for the current status, then update the loader when a new build is announced.
