MAKE IT YOURS

More control over every scene.

Scooby brings one organized modding interface to the 32-bit Windows versions of Left 4 Dead 1 and Left 4 Dead 2. It is included with every authenticated free or paid account; there is no separate L4D purchase.

Use the loader's Start Game popup to choose either game. The dashboard detects running games and lets you choose explicitly when both are open.

Infected & pickup ESP

Identify common and uncommon infected, witches, tanks and special infected. Set type-specific colors, boxes, skeletons, names, health and distance. Give dropped weapons, medical supplies, ammo and items their own visuals.

Independent chams

Customize players, self, arms, held weapons, dropped weapons, items and infected types. Visible and invisible passes have independent toggles, colors and materials, with wireframe, pulse and rainbow effects.

Rage & Legit

Separate aim and triggerbot profiles with target filters, hitbox selection, aim keys, FOV circles, snaplines and target dots. Explore lock-on, silent modes, smoothing, recoil and spread controls during local testing.

World & View

Tint world materials, props and sky. Adjust camera FOV, viewmodel FOV and X/Y/Z offsets, or use third person with camera distance and shoulder controls.

Movement & overlays

Bunnyhop and auto-strafe controls pair with radar, movement telemetry, hotkey displays and an FPS watermark. Give features their own keys and colors.

Lua, configs & languages

Build custom pages, overlays and tools with the Lua editor and L4D host API. Save profiles, select from 23 language catalogs, and adjust menu text, UI and overlay scale independently.

Getting started

  1. Sign into the Scooby Loader with an existing paid account or a valid free key. New users can choose Get Free Key above.
  2. Open Left 4 Dead in the loader, then choose Start Game → Left 4 Dead 1 or Left 4 Dead 2.
  3. Wait for the selected game to reach its menu and appear in the dashboard.
  4. Choose Load, start a local single-player map, and press Insert.

Common questions

Do I need an L4D subscription?

No. L4D is included with any authenticated paid account or valid free-key session. Existing free keys retain their normal expiration.

Does it support both games?

Yes, through separate verified adapters in one 32-bit module. Choose the desired game in the loader; it automatically selects a newly detected single running game.

Which renderers are available?

The Windows game integration uses Direct3D 9. Vulkan/DXVK can be used when the installed game provides that renderer. The OpenGL UI backend and preview are available for verified compatible ports; stock Windows L4D installations do not provide a native OpenGL game renderer.

Can I write custom Lua features?

Yes. The API reference covers snapshots, infected and pickup queries, projected boxes, bones, rendering, hotkeys and custom controls. Lua reads copied game data; scripts do not run as the game's VScript engine.
