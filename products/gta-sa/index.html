Description

Scooby brings a configurable cheat interface to classic Grand Theft Auto: San Andreas. Browse player, NPC and vehicle visuals, adjust your targeting controls, use the world map and manage your own settings and scripts.

The release includes an on-foot teleport implementation for map waypoints and coordinates, position history, and health tools. Gameplay features require the exact supported executable and an active single-player session. Live gameplay and performance acceptance are pending.

Visuals & targeting

Separate ESP profiles for players, NPCs, vehicles and self. Target filters, aim radius, smoothing and prediction controls.

Explore San Andreas

World-map blips, menu waypoints, coordinate teleport, Back and session-local saved positions. Teleports currently require being on foot.

Make it yours

Feature settings, keybinds, saved profiles and Lua scripting, stored separately from other Rockstar titles.

Getting started

  1. Get a valid Scooby free key using the button above.
  2. Open the updated Scooby Launcher and sign in. Select Rockstar Classics → San Andreas → Classic.
  3. Start Classic San Andreas, then press Load. The loader detects the running game and prepares the required files automatically. No executable picker is needed.
  4. Press Insert or F1 to open the menu after authentication.

Windows x86, classic single-player only. Only the executable identified in the release manifest is supported. Definitive Edition, MTA and SA-MP are unsupported.
