## Public asset acquisition

`tools/menu-sources/download-cherax-assets.cjs` prepares a resumable, ignored local
staging folder at `project/community-menu-sources/cherax-downloads`. It reads only
the pinned public ModVerse snapshot and selects 3,162 resource payloads plus their
3,162 associated thumbnails. Generated covers are acquired as associated assets
and retain their cover labels. No Lua is acquired or executed, and archives are
stored intact without extraction.

```powershell
node tools/menu-sources/download-cherax-assets.cjs --inventory
node tools/menu-sources/download-cherax-assets.cjs --download
node tools/menu-sources/download-cherax-assets.cjs --check
```

Only `--download` uses the network. It uses three workers, validates allowed public
GitHub redirect hosts, rejects executable/HTML bodies, verifies image/archive/RPF
magic and the Cherax Entity JSON structure, and enforces a 100 MiB per-file cap.
HTTP throttling pauses new requests with a recorded retry time and exit code 75.
The index is saved in bounded batches and on errors; rerunning resumes saved
records and validates their bytes. `--check` is an offline completeness and actual
byte/hash check, returning nonzero until every selected asset is downloaded.

Each successful `asset-index.json` entry includes its source/resource IDs,
category, role, source URL, original name, actual served size/SHA256/magic, separate
publisher byte claims, staged local path and publishing `targetRelativePath`.
Publishing paths match the existing content-addressed namespaces
`downloads/gta5/menus/cherax/<actual-sha256-first20>.<magic-extension>` and
`previews/gta5/menus/cherax/<actual-sha256-first20>.<magic-extension>`. This helper
never writes `cool-repo` or pushes a repository. The publishing task must copy only
validated `status: "downloaded"` records and preserve exact JSON bytes with a
narrow `-text` rule in the dedicated download directory. A global Git text rule
must not be changed merely to publish these assets.
