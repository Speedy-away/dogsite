SCOOBY LOGO PACK — 15 DESIGNS

Extract the ZIP, then open index.html for the animated gallery. No server or internet needed.

CONTENTS
png/: 15 original transparent PNGs, 1280 × 1280.
animated/: 15 self-contained 512 × 512 SVG files embedding the PNG artwork.
index.html + gallery.css + gallery.js: filterable gallery with motion toggle and transparency checkerboard.
manifest.json: names, categories, file paths and motion styles.
generation-prompts.json: prompts for the 11 new variants, generated with the built-in image_gen tool. The four earlier variants are included from the existing project assets.

ANIMATION
Gentle float, nod, sway and pulse loops; space and mage designs include twinkling stars; diver has rising bubbles. These are whole-logo motion effects, not frame-by-frame character animation. SVGs retain transparent backgrounds. Reduced-motion preferences disable CSS animation. For a guaranteed static image, use the PNG.

USE ON A WEBSITE
<img src="animated/astronaut.svg" width="96" height="96" alt="Scooby astronaut">
Use PNGs in applications that do not support animated SVG. SVG wrappers contain raster artwork; they are not editable vector drawings.
