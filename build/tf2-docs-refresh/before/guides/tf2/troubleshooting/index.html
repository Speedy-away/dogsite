Troubleshooting

Resolve edition selection, loading, missing menu, empty data and script errors.

Troubleshooting

The loader cannot find my game

Check Game version first: retail and Classified have different executables. Close duplicate instances of the selected game. Start that edition through the dashboard, or restart it through Steam with -insecure. Wait for the game to reach its menu before retrying.

The game changed after an update

Use the latest matching TF2 package. The native adapter checks the supported game build and can reject changed modules. Do not substitute files from the other edition; wait for a compatible update when the current build is unsupported.

The package is incomplete or fails verification

Use the latest Scooby Launcher, check your connection and retry Load. The launcher downloads and verifies the selected edition automatically; the game then downloads fonts and menu assets automatically. Watch the progress bar at the bottom of the screen for the current filename. If a download pauses, check your connection and press F5 to retry; verified files are reused. Keep your user-data backup; replacing a runtime package does not require deleting profiles.

Loaded, but the menu does not appear

Focus the game and try Insert or F1. Read the loader’s exact status. If it reports that startup did not accept the session, restart the game and sign in again before retrying. A loaded library alone does not prove that every gameplay feature is active.

ESP or Lua queries show no data

Enter an eligible local practice/listen-server map and wait for a live local player. Check feature toggles, team/category filters and ranges. In the API, inspect tf2.session(); empty results are expected while disconnected, after Stop or in an ineligible session.

A model preview is empty

Preview assets download automatically after loading. The full menu becomes available once all files are verified; later launches reuse the cache. Restart the game and load the latest matching edition. If the preview remains empty, include your edition and the relevant log when reporting it.

A language download fails

Your installed languages remain available if a download fails verification. Check your connection and try Download / update languages again. English works without downloading a pack. Locally edited language files are preserved during updates.

A script reports an error

Open the Lua console, check the named line and function, and compare the example with the TF2 API. Check nil results and API version 1.0. Stop the script, correct it and run it again. Script callbacks and UI are cleaned up when the script is stopped.

For further help, include your edition, loader message, reproduction steps and the relevant console error. Avoid sharing passwords, keys or session data.
