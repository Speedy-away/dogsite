About the pre-release

Scooby Overwatch brings configurable on-screen information and world FOV controls to a PS4 menu operated with R1 + Square. Enemy and team visuals can be adjusted and stored in profiles.

Version 1.0.0 is a pre-release development build. The public release is coming soon; the feature list below reflects current development progress.

CURRENT DEVELOPMENT BUILD

Current features

  • Enemy and team ESP with distinct coral enemy and cyan teammate colors.
  • Radar with matching enemy and teammate markers.
  • Boxes, health bars and snaplines.
  • Metric distance labels and off-screen indicators.
  • World FOV adjustment from 70–120°.
  • R1 + Square menu controls and saved configuration profiles.
STILL IN DEVELOPMENT

Unfinished / unavailable

  • Skeletons and tighter box fitting: refinements are unfinished.
  • Head markers, player nicknames, weapon labels and visibility checks: unavailable.
  • Aim features, model FOV and bullet tracers: unavailable.
