What you can do

Manage files
Browse available console storage and connected drives, copy or move files, and recover deleted items from the Bin.
Extract archives
Open supported ZIP, RAR and 7z archives or extract their contents from File Explorer.
Download and install
Save files to Downloads, track their progress, and review local PS4 packages in PKG Installer.
Use Scooby Web
Pair a browser on the same network to browse and download files. Approve an upload folder on the console when you want to send files back.
