# Scooby Overwatch 1.0.0 Beta

Free PS4 release for Overwatch CUSA03974, game version 04.40.

Open the menu with **R1 + Square**. Features include enemy/team visuals, boxes, health bars, snaplines, metric distance labels, off-screen indicators, radar, world FOV 70–120, and configuration profiles.

See TRANSFER.txt for installation and the notification icon. Keep the Licenses folder with this package. The complete optional default profile is OverwatchVisualDefault.json; existing profiles can be kept.

This Beta has a verified menu-load/render observation. See KNOWN-ISSUES.md for its current limits. Downloads and support: https://scoobymenu.cc
