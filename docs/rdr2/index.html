Developer reference files

The host creates Documentation.json, DataNodes.lua and natives.lua automatically. The two Lua files are editor annotations and cannot execute or load as modules. Gameplay scripts use the built-in API.

These downloads describe this game's supported bindings. GTA5 node schemas are not RDR2 layouts; unavailable entries retain their reason.

Runtime and availability

Lua 5.4.6 / LuaJIT 2.1. 4,859 supported typed native signatures from 7,130 declarations. Host access checks and game-callback requirements apply to feature commands.

Source and contract validation do not establish live in-game behavior, input or performance. Check each API signature and availability badge before using it.
