Run your first script

  1. Open the in-game Lua / Scripts manager or Lua Editor.
  2. Use its folder control to locate your editable scripts, then add a downloaded .lua example.
  3. Refresh the list, select the file and choose Run. Bundled examples do not run automatically.
  4. Use Stop for that script before editing or reloading it. Open the console for the error line and callback name if it fails.

The HUD and player labels draw only when an eligible local session supplies live data. Edition Info also works without a live player.

Read tf2.capabilities() and check individual settings with tf2.has_feature(id). Capabilities describe implemented interfaces, not complete gameplay acceptance.

Check the running edition
assert(type(TF2_API_VERSION) == "string" and TF2_API_VERSION:match("^1%."), "Update the TF2 Lua host")
local info = tf2.info()
local caps = tf2.capabilities()
print(info.game, info.game_id, info.api_version)
print("Four teams:", caps.four_teams, "Civilian:", caps.civilian)
print("Game data available:", tf2.session().data_available)

Work with snapshots

Check tf2.session().data_available, handle nil and reacquire player/entity tables inside each callback. Map changes, disconnects, an ineligible session or Stop can make game queries empty. Returned tables are copies; editing one does not write game memory.

Stopping a script removes its callbacks and UI. Changes made to built-in settings remain and can be saved in a profile. Raw native hook APIs are not provided by the TF2 extension.

Download the complete host contract, Classified contract or shared UI reference for behavior and limits.
