5

Limitations

Pickup ESP

The tab is present but disabled; pickup enumeration is not supplied by the current adapter.

Spawner operations

Spawner operations remain unavailable.

Vehicle teleport and region changes

Vehicle teleport and changing interior or dimension are not implemented.

Spectator telemetry

The current adapter does not provide spectator telemetry.

Full MTA resources

Native resources, meta.xml, resource exports, remote/server events, engine object creation and compiled Lua are not supported by Scooby's script runtime.
