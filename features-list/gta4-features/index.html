Released for exact Windows x86 GTA IV 1.0.7.0, 1.0.8.0 and Complete Edition 1.2.0.59 executables. Includes instant-hit and sniper delayed-hit silent aim. Projectile/explosive silent aim, standalone EFLC and other executable builds are not supported. Feature availability depends on the supported game build and active session. Recent local DLL updates listed below are not yet confirmed in the published loader release. Pickup names and fire/explosive ammo remain unfinished; pickup boxes currently use a small 3D position marker.

Visuals and spawners

Quick spawn

Optional one-click vehicle spawning and weapon giving using the selected spawn settings.

Scrollable catalogs

Mouse-wheel scrolling and a visible scrollbar for vehicle and weapon lists.

Attached vehicle information

A panel attached to the menu lists the selected vehicle name, model, class, episode and spawn name.

3D vehicle and pickup boxes

Vehicles use rotated model bounds. Pickups use a small 3D marker; actual pickup names are not implemented.

NPC and Self previews

Civilian NPC and Niko previews reflect the selected ESP profile. Preview health and distance affect only the preview.

Health settings

Smooth health bars with HP text inside Health settings, plus independent weapon and ammunition labels.

Longer default ESP range

Fresh settings default to 1,000 metres for entities available to the game. Existing saved ranges are preserved.

Movement inside Self

Movement controls now sit under Self. Noclip position and camera free-look fixes still require in-game verification.
