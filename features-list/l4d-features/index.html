Capture Protection

4
Link to this section ↗
Capture Protection

Move the menu, ESP, radar, HUD and compatible Lua overlays to a separate capture-excluded surface. Requires Windows 10 2004 or newer. Recorder compatibility depends on its capture method; check the actual OBS recording or Discord share.

Blocked features and hover explanation

Incompatible controls are blurred or dimmed and cannot be enabled. Hover to see: Capture Protection is enabled. Disable it to use this feature.

  • Disables chams, native glow, world/sky effects and materials
  • Disables camera/viewmodel changes, recoil camera removal and vomit removal
  • Disables native Lua hooks and incompatible script features
Keep your tuning and shortcuts

Retain colors, material choices, numeric settings, presets and hotkeys. Turning Capture Protection off unlocks the controls; it does not automatically turn cleared effects back on.

Pause and recover protected rendering

Hide protected UI while minimized, backgrounded or recovering from a renderer failure. Retry without drawing that UI into the game surface.

Custom material library

Use Open folder, add same-name VMT/VTF pairs and press Refresh. Supported shaders are VertexLitGeneric and UnlitGeneric; start from Add example.

  • Up to 32 materials
  • Single-frame 2D VTF 7.2–7.5, power-of-two textures up to 1024 × 1024
  • RGBA/ABGR/ARGB/BGRA8888, RGB/BGR888, DXT1, DXT3 and DXT5
  • Supported switches, alpha and TextureScroll; arbitrary shaders/proxies are not imported
Automatic PNG and GIF previews

Place name.png or name.gif beside name.vmt and name.vtf. The matching basename selects the preview automatically.

  • PNG takes priority when both exist
  • GIF previews animate; the game uses the VTF texture
  • Missing or invalid images fall back to a VTF thumbnail
