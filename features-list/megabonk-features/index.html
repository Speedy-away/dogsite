Spawner

5
Link to this section ↗
Spawn pickups

Spawn pickups around your current position. Nearby XP and gold can merge into existing piles.

  • XP, Gold, Health, Nuke, Time, Shield, Rage, Haste, Stonks, Magnet and Silver
  • Quantity: 1-25 per batch
  • Distance from player: 0-8 metres
  • XP and gold value: 1-10,000 per pickup
  • Powerup limits apply
Give items

Search the game item catalog and add the selected item to your run inventory.

  • Quantity: 1-25 per batch
  • Item stack limits and challenge restrictions apply
Collect all XP

Collect the XP pickups available in your current run.

Action progress and cancellation

Follow batch progress and cancel remaining actions. Completed actions stay applied.

Refresh content list

Reload the available item and unlock choices from the current game catalog.

Unlocks

2
Link to this section ↗
Unlock selected content

Complete the selected content's required quests and unlock it without spending silver, then save progression.

  • Characters, weapons, tomes, items, maps and hats
  • Search content by name
  • Existing disabled-content choices are preserved
Unlock a whole category

Unlock all available content in the chosen category and save completed progress.

  • Cancel remaining unlocks while a batch is running
  • Already completed actions are not reversed
  • Unlocks affect saved progression and required quest completion
