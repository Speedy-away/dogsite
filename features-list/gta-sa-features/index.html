Teleport to waypoint

Use the menu waypoint first, otherwise the game radar waypoint. Requires the exterior world and a successful ground query. On-foot in the current beta. Occupied-vehicle teleport is planned for the next update; in-game verification pending.

Teleport to coordinates

Use X, Y and Z coordinates with optional ground snapping. Invalid or unloaded destinations are rejected. On-foot in the current beta. Occupied-vehicle teleport is planned for the next update; in-game verification pending.

Back

Return to the previous teleport position in this session. On-foot in the current beta. Occupied-vehicle teleport is planned for the next update; in-game verification pending.

Copy current coordinates

Set menu waypoint

Choose a menu waypoint; you can also right-click the world map. On-foot in the current beta. Occupied-vehicle teleport is planned for the next update; in-game verification pending.
