Troubleshooting · Half-Life 1

Resolve edition mismatches, unavailable controls and missing assets.

Troubleshooting

Which games share this guide?

Half-Life 1, Half-Life: Blue Shift, Half-Life: Opposing Force and Half-Life: Source belong to the same Half-Life 1 collection in Scooby. Use the version dropdown to match your installed edition.

Which files should I use?

Half-Life 1, Blue Shift, Opposing Force and Half-Life: Source are supported editions. Select your installed game and use its matching files. Sharing the product page does not make edition-specific game files interchangeable.

The Load action is unavailable

The original Windows campaign package has passed its runtime checks. Authenticated loader package integration is still pending. A DLL in the distribution folder is not a released loading option.

Missing text, fonts or Lua pages

Keep the matching module, fonts, languages and Lua assets together. Keep your writable profiles separate from the package and preserve them when updating.

Features stop after leaving a map

Session-bound visuals clear when their supported local game session ends. Load a supported local map and check the status before enabling features again.

Need more help?

Include the selected edition, Steam build, renderer and loader status when contacting support. Never include passwords or access keys.
