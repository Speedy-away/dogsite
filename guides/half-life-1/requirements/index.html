Download VC Runtimes

Install the Visual C++ runtimes before launching Scooby. Choose the all-in-one package or install both Microsoft packages below, then restart your PC.

Download VC Runtimes — x64 (64-bit) Download VC Runtimes — x86 (32-bit)
  • Original Half-Life on Steam, using the Windows 32-bit game and OpenGL renderer.
  • The current original-game reference is Steam AppID 70, build 15961492. Compatibility is checked against the exact game files.
  • The Half-Life 1 collection includes Half-Life: Blue Shift, Half-Life: Opposing Force and Half-Life: Source. Select the edition you have installed; its game files and support status remain specific to that edition.
  • Half-Life and Opposing Force have passed their native Windows runtime checks. Blue Shift and Half-Life: Source are also supported editions in this collection. Follow the status shown in the loader before loading a module.

Linux through Proton/Wine is being tested separately. Native Linux game binaries and software rendering are not covered by the current Windows OpenGL adapter.
