Getting started · Half-Life 1

Choose Source Games, Half-Life 1 and your installed edition.

Getting started

  1. Download Scooby and sign in with your existing account.
  2. In the game selector, open Source Games → Half-Life 1.
  3. All four games share the Half-Life 1 dashboard and this guide. Use Game version to choose Half-Life 1, Half-Life: Blue Shift, Half-Life: Opposing Force or Half-Life: Source. Match the installed edition.
  4. Enable Start game if you want Load to launch your selected Steam title. A game that is already running will be detected. Use OpenGL for Half-Life 1, Opposing Force and Blue Shift; Half-Life: Source uses Windows x86 with Direct3D 9.
  5. Select Load. Scooby downloads and verifies the files for your chosen edition, then waits for the matching game. All four editions have free access. Use F2, Insert or your saved menu key to open the menu.

Use Open Scooby folder to prepare and open the files for the selected edition. Use the wiki navigation for setup and feature details.
