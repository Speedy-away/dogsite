Guides/GTA 5/Customization

Themes

Install a shared theme, keep its images together, and save the look of ClickUI, ListUI, or both.

Themes

Scooby themes can include colors, layout settings, backgrounds, and other image layers. A theme may be a single JSON file or a folder containing its settings and images.

Theme folder and menu

C:\scooby\GTA5\themes
Settings → Appearance → Themes
Use Open Themes Folder to open the correct location.

InstallApplySave and shareTroubleshooting

Install a downloaded theme

  1. Get a Scooby GTA 5 theme from its author or the Scooby community. Extract the archive first.
  2. Open Settings → Appearance → Themes → Open Themes Folder.
  3. For a single-file theme, copy the .json file directly into C:\scooby\GTA5\themes.
  4. For a theme bundle, copy the entire theme folder into themes. Keep its JSON and image files together, with the author's filenames and relative paths unchanged.
  5. Return to the menu and select Refresh Library.

Example layouts (the image filenames in your download may be different):

C:\scooby\GTA5\themes\
    SimpleTheme.json
    MyTheme\
        MyTheme.json
        background.png

The theme JSON should sit at the top of its bundle folder. Avoid accidentally adding an extra wrapper folder when extracting a ZIP.

Apply a theme to the interface you use

  1. Select the theme in the library.
  2. Choose Save / Load Scope: Both, ClickUI, or ListUI.
  3. Select Load Selected Theme. Check the status message and the chosen interface.

Both applies the available settings for both interfaces. ClickUI or ListUI applies that interface and its shared appearance settings. The theme must contain settings for the scope you choose; a ClickUI-only theme cannot supply a ListUI design.

Save, back up, and share your design

  1. Adjust the appearance settings and choose the scope you want to save.
  2. Enter a new custom theme name and select Save Current Theme.
  3. Scooby creates C:\scooby\GTA5\themes\YourTheme\YourTheme.json and bundles referenced images into the theme folder.
  4. Use Open Selected Folder to find the result. Back up or ZIP the entire folder when sharing it.

Quick Save updates the selected custom theme. Use a new name when you want to keep the previous version. Built-in themes are protected from overwriting and deletion; save a custom copy to edit them.

If the theme does not look right

  • Not listed: extract the archive, check that the JSON is directly in themes or directly inside its bundle folder, clear the search, and refresh.
  • Missing background or images: copy the complete bundle again. Sharing only its JSON can leave referenced images behind.
  • Only one interface changes: check Save / Load Scope and the interfaces included in the theme.
  • Load fails: restore the original JSON and confirm the theme supports your Scooby version. A theme from another menu is not automatically compatible.
  • Want to undo a change: load a previously saved theme or a built-in theme from the library. Save your current design before experimenting if you want to keep it.
