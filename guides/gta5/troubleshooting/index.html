Troubleshooting

Here are solutions to common issues you may encounter:

Plus: Hypervisor / VBS is running

Use the VBS/HVCI troubleshooting guide and check_vbs.bat download to identify the trigger. For Secure Boot, Fast Boot, driver loading or boot failures, start with the Plus Setup Guide.

The BattlEye-disabled injection fixes below apply to the corresponding free / non-Plus loading path. For the Plus bootloader path, follow the Plus guide and keep BattlEye enabled.

Failed to allocate memory in target process

Head to your Rockstar Launcher, click on Settings, and disable BattlEye. This will fix the issue.

Please return to Grand Theft Auto V (Black Screen)

You must inject the menu during the loading screen. This message means the game is signifying you're going back to story mode.

BattlEye is required to play GTA V Online

Same solution - inject the menu during the loading screen, not when you're already in the game.

Black screen with an error message

Restart your game without opening Scooby and go to story mode before injecting. Frame Generator is now supported, so you no longer need to turn it off.

Failed to write process memory

Turn off BattlEye in the Rockstar Launcher settings.

Launcher, free key & injection troubleshooting

Follow this guide if the launcher closes after opening, the free key website is unreachable, injection fails, or injection succeeds but the menu does not work in game.

  1. Check your connection. Try a VPN, then retry the website or launcher. Your network or ISP may be blocking the connection.
  2. Clear the cache if the launcher still closes or injection fails. Close Scooby, delete the C:\scooby folder, then restart Scooby and try again.
  3. If injection still fails, check whether antivirus is blocking the loader. Follow the Antivirus & Download FAQ for the next steps.

If only the free key website is affected, you do not need to reset the launcher cache. If the issue continues, contact support with the error message and the steps you have tried.

Not listed here?

See Universal Troubleshooting in the General tab - it covers "Failed to inject module", Auth Failed, crashing on inject, BattlEye kicks and the Scooby folder going missing. If Windows is flagging or deleting the loader, start with the Antivirus & Download FAQ.
