Vehicles

Install shared vehicles, import compatible menu exports, and save your own customized rides.

Vehicles

Saved Vehicles stores reusable vehicle presets. These files describe a vehicle and its saved settings; the underlying model must already be available in your game.

Vehicle folder and menu

C:\scooby\GTA5\vehicles
Vehicle → Saved Vehicles → Browse in ClickUI and ListUI.
Supported preset formats include .json, .xml, and .ini.

Download vehicles

Browse and download vehicles from Nenyoo ↗

Check the download’s file format and edition requirements before importing it. Extract the archive first, then use the installation steps below.

Check Legacy / Enhanced compatibility

Choose a download made for your game edition and a format Scooby supports. Addon models and textures may need conversion between Legacy and Enhanced; a saved preset does not perform that conversion. See addon edition and conversion help.

Install and spawn a shared vehicle

  1. Download a compatible vehicle preset from Nenyoo vehicles or its author, and extract it if it is inside an archive.
  2. Open Vehicle → Saved Vehicles and select Open Folder, or paste C:\scooby\GTA5\vehicles into File Explorer.
  3. Copy the preset into the vehicles folder or your own subfolder. Keep the original extension.
  4. Open Browse, select Refresh, and open the folder containing the vehicle.
  5. Select the vehicle to spawn it. Enable Spawn Inside if you want to enter it automatically. 3D Preview shows a preview when one is available.
C:\scooby\GTA5\vehicles\
    MyVehicle.json
    Favorites\
        SharedVehicle.xml

Keep personal saves in the parent folder or your own subfolders. vehicles\PresetVehicles is used for bundled presets.

Import a vehicle from another menu

Place the original export in the matching folder:

  • Stand: C:\scooby\GTA5\other-menu-addons\stand-vehicles
  • Cherax: C:\scooby\GTA5\other-menu-addons\cherax-vehicles
  • Other supported exports: C:\scooby\GTA5\other-menu-addons\other-menus-vehicles

Open Other Menu / Other Menus in Saved Vehicles, refresh, and choose the import. Compatible .json, .txt, .ini, and .xml exports can be scanned. Keep files directly in the matching folder and preserve their original structure; an extension alone does not guarantee support.

The installed format notes are in C:\scooby\GTA5\other-menu-addons\VEHICLES-GUIDE.txt.

Save and share your own vehicle

  1. Enter the vehicle you want to save and finish customizing it.
  2. Open Vehicle → Saved Vehicles → Save Vehicle, or browse to the subfolder where you want to save.
  3. Choose JSON [SCOOBY] for a native Scooby save, XML [Menyoo] for a Menyoo-compatible export, or INI [Other Menus] for a supported INI export.
  4. Select Save Current Vehicle and enter a filename without an extension. Scooby adds the selected extension.
  5. Use Open Folder to copy, back up, or share the file. Include any model or edition requirements when sharing.

Save as Personal Vehicle opens the garage registration flow. Use Save Current Vehicle when you want a portable file; saving a preset is separate from registering a personal vehicle.

If a vehicle will not appear or spawn

  • Missing preset: check the folder and extension, clear the search, open the correct subfolder, and refresh.
  • Cannot save: enter a valid vehicle first and use a simple filename.
  • Cannot spawn: the model may be unavailable in your game build, or the preset may use an unsupported structure. Restore the original download or ask for a compatible export.
  • Wrong format: select the intended save format before saving. Changing .xml to .json does not convert the file.
  • Downloaded an RPF or model assets: follow Addons. The saved-vehicle folder does not install custom game assets.

Back up the vehicles folder and import folders while Scooby is closed. In ListUI, pressing Right on a local library entry permanently deletes that file.
