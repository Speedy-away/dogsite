Outfits

Install shared outfits, import supported exports, and save your own clothing presets.

Outfits

Saved Outfits lets you keep clothing components, textures, and props in portable files. Use a preset made for the same ped or freemode character model as your character.

Outfit folder and menu

C:\scooby\GTA5\outfits
Self → Outfit Editor → Saved Outfits in ClickUI and ListUI.
Native saves use .json; supported .xml outfits can also be loaded.

Install and wear a shared outfit

  1. Download the outfit from its author or the Scooby community. Extract the download if it is an archive.
  2. Open Saved Outfits and use Open Folder / Open in Explorer, or paste C:\scooby\GTA5\outfits into File Explorer.
  3. Copy the compatible .json or .xml outfit into that folder. You can organize native saves in your own subfolders.
  4. Return to Saved Outfits, select Refresh, and open the folder containing the file.
  5. Select the outfit to apply it. If clothing looks wrong, switch to the character model it was made for and load it again.

Import an outfit from another menu

Keep the original export format and place it in the matching import folder:

  • Stand: C:\scooby\GTA5\other-menu-addons\stand-outfits
  • Cherax: C:\scooby\GTA5\other-menu-addons\cherax-outfits
  • Other supported exports: C:\scooby\GTA5\other-menu-addons\other-menus-outfits

Open the Other Menu / Other Menus outfit library, refresh, then select the import. Compatible .json, .txt, .ini, and .xml exports can be scanned; the file's internal structure must also be supported. Keep imports directly in the matching folder to make them easy to find.

For the format notes included with your installation, read C:\scooby\GTA5\other-menu-addons\OUTFITS-GUIDE.txt.

Create, save, and share your own outfit

  1. Use Outfit Editor to choose the clothing components, textures, and props you want.
  2. Open Saved Outfits. Browse to your destination or select New Folder.
  3. Select Save Current Outfit and enter a filename without an extension. Scooby adds .json automatically.
  4. Use Open Folder to find the saved file. Copy it to a backup or share it together with the character model it was created for.

Wardrobe Manager manages GTA's in-game wardrobe slots. Use Saved Outfits when you want a portable file.

If an outfit is missing or looks wrong

  • Missing file: check its extension and folder, open the correct subfolder, and refresh. Other-menu exports may need the import library instead.
  • Refuses to load: restore the original file or ask for a supported export. Renaming a file extension does not convert it.
  • Wrong clothing: component and prop indexes differ by model. Use the same ped and male/female freemode model as the original outfit.
  • Downloaded model assets: .ydd, .ytd, and RPF packs are not outfit presets. See DLCs (Vehicles and Peds).

Back up the outfits folder and any import folders while Scooby is closed. In ListUI, pressing Right on a local saved outfit deletes its file permanently.
