First Time Setup

Using Plus with BattlEye enabled?

Follow the Plus Setup Guide for the reboot-based kernel loader and interface-specific menu keys.

When installing Scooby for the first time, follow these steps:

Step 1: Download

Head over to scoobymenu.cc and click the download button to get the Scooby Installer. Make sure your anti-virus is turned off.

Step 2: Extract & Run

Extract the files into any folder. After that, run the .exe as an administrator. This ensures the launcher will run successfully.

Step 3: Install Requirements

Download VC Runtimes

Install the Visual C++ runtimes before launching Scooby. Choose the all-in-one package or install both Microsoft packages below, then restart your PC.

VC Runtimes (all-in-one package):

Download the all-in-one VC runtime package

Or install both packages directly from Microsoft:

Download VC Runtimes — x64 (64-bit) Download VC Runtimes — x86 (32-bit)

DirectX:

https://www.microsoft.com/en-gb/download/details.aspx?id=6812

Make sure you have your graphics drivers up to date.

Step 4: Inject

Load up GTA and wait for it to be on the main menu or in story mode. Then go back to the launcher, get a free license, and follow the steps.

When you have acquired your free license, click Inject. This should inject the menu into the game. Open ClickUI with F1 / Insert, or ListUI with F2.
