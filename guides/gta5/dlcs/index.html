Guides/GTA 5/Customization

Addons

Download addon vehicles and peds, check Legacy / Enhanced compatibility, and find models available in your game.

Addons

Scooby can browse vehicles and peds (character models) from GTA 5 title updates. A downloaded vehicle preset, outfit, and custom DLC pack are different kinds of content. Start by checking what the download contains.

Download addons

Download addon vehicles ↗Download addon peds ↗

Read the author’s description for your edition, required tools, installation steps and model spawn name. These are addon asset packages; saved vehicles and outfits have separate guides.

Legacy and Enhanced use different addon asset formats

Download the version made for your GTA 5 edition. A Legacy addon vehicle, ped or texture may need conversion to Enhanced’s asset format before it works in Enhanced. An Enhanced asset is not automatically compatible with Legacy either.

Prefer the author’s release for your edition. If conversion is needed, use the author’s instructions or the Sollumz Legacy → Enhanced asset-conversion guide. Its CodeWalker workflow covers supported model and texture assets. Renaming a file extension does not convert it.

Saved vehicle and outfit presets are different: a JSON / XML preset references models, clothing and settings. It does not convert or install the underlying assets. Check the preset’s model, character and edition requirements too.

What are you trying to install?

  • A saved vehicle: a compatible .json, .xml, or .ini preset belongs in the saved-vehicle library. Follow Vehicles.
  • A saved outfit: a native .json or supported .xml clothing preset belongs in Saved Outfits. Follow Outfits.
  • A custom vehicle or ped model: a download containing dlc.rpf, .yft, .ydd, or .ytd is a model/asset package. The outfit and vehicle preset folders do not install these game assets.

Install the addon’s assets first

Use the pack author’s instructions and a compatible asset loader for your exact GTA 5 edition. Scooby’s saved-vehicle and outfit folders store presets; copying dlc.rpf into them does not install an addon. A preset or model selection can only use assets the game can load.

Find and spawn a built-in DLC vehicle

  1. Open Scooby's Vehicle menu, then Open Vehicle Spawner.
  2. Use the DLC filter to select a title update, or choose All to search across releases.
  3. Use Class and the name search to narrow the list. Clear these filters if a vehicle seems to be missing.
  4. Select an available vehicle to spawn it. If you customize it and want a reusable file, follow the vehicle saving steps.

Built-in DLC models come from your installed game files; you do not need to download a shared vehicle save just to browse them.

Choose a DLC ped or character model

  1. Open Self → Outfit Editor → Model Changer.
  2. Search by name and choose a Category and DLC. Set the DLC filter to All to widen the results.
  3. Select a model to apply it. Save your current outfit first if you want to return to its clothing later.
  4. Use an outfit made for the selected model. Clothing components and props can differ between male and female freemode characters and other peds.

If a model is missing or will not load

  • Nothing in the list: clear the search, category/class, and DLC filters. A favorites-only view can also hide models.
  • Model unavailable: check that it exists in your installed GTA 5 edition and build. A name in a catalog or shared preset does not add the model to your game.
  • Custom pack does not appear: check the pack author's edition requirements and installation steps. Refreshing Saved Vehicles only rescans presets.
  • Wrong clothing after changing ped: switch to the model the outfit was created for, then load the outfit again.
