Connection & SSL errors

Check your clock, connection and error message before changing network or security settings.

Connection & SSL errors

Connection checksSSL / certificate errorsTest another networkStill stuck?

Work through these in order

  1. Check that other websites open. If everything is offline, fix your network connection first.
  2. Retry the official Scooby website and loader after a short wait. An outage or maintenance can affect both.
  3. Open Windows Settings → Time & language → Date & time. Correct the date, time and time zone; use Sync now if available.
  4. Restart the browser or loader. Finish a hotel, school or public Wi-Fi sign-in page in the browser if one is required.
  5. If a VPN or proxy is already enabled, disconnect it briefly and test again. Restore your normal setting afterward.

If the error mentions SSL or a certificate

A certificate error is not proof that your ISP blocks Scooby. A wrong clock, outdated Windows, a sign-in portal, security software inspecting HTTPS or a server problem can all cause it.

  • Correct the clock, apply Windows updates, then restart.
  • Check antivirus history for a named web-protection block. Follow the vendor’s official help for that detection.
  • Do not bypass certificate warnings, install an unknown root certificate or disable the firewall to make the message disappear.

Check whether the network is the problem

If the error remains, try a trusted alternative connection, such as your phone’s hotspot. If it works there, the original network may be filtering the connection.

A VPN can help diagnose routing or filtering problems on your own network, but it cannot fix every SSL or authentication error. If you already use one, test another server or test with it disconnected. On a work or school network, ask the administrator about its access rules.

If you still need help

Include the exact error text, whether it happens in the browser or loader, your Windows version, antivirus name, and whether the hotspot test changed anything. Hide passwords, keys and other private details.

If the network works but sign-in fails, follow authentication troubleshooting. For an HWID mismatch, use the portal reset guide; resets have a 7-day cooldown.
