Crashes & loading errors

Start with a few simple checks. Change one thing at a time so you can tell what helped.

Crashes & loading errors

Start hereMissing runtimesReset settingsStill crashing?

Try these first

  1. Close Scooby and the game. Restart the PC if they will not close normally.
  2. Launch the game without Scooby once. If it still crashes, repair the game first using its launcher’s Verify / Repair option.
  3. Download the current loader from Scooby’s website and follow your game’s setup guide. Use the correct edition and account tier.
  4. Read any antivirus alert before changing settings. A missing or quarantined file belongs in antivirus & download help.
  5. Apply pending Windows updates and get graphics drivers from your GPU maker. Test again after restarting.

Missing DLL or Visual C++ error?

Install or repair the current Microsoft Visual C++ Redistributable packages. On a 64-bit Windows gaming PC, install both packages below, then restart.

Microsoft Visual C++ · x64 ↗Microsoft Visual C++ · x86 ↗

Use Microsoft installers rather than downloading individual DLL files from a DLL website. For DirectX errors, repair the game’s prerequisites through its launcher.

Test with fresh settings without losing your backup

  1. Close both Scooby and the game.
  2. Open File Explorer with Win + E. Check C:\scooby and your Documents\Scooby folder; use the one that actually contains your settings. Press Alt + D to enter a folder path in the address bar.
  3. Select the Scooby data folder and press F2, or right-click it and choose the Rename icon. Enter an unused backup name, such as scooby-backup, then press Enter. Keep its scripts, outfits and presets in the backup. Do not rename a whole Documents folder or the loader executable.
  4. Open Scooby so it can create fresh settings. Test without imported scripts, themes or presets.
  5. If it works, restore your saved items gradually to find the cause. If it does not, close Scooby before restoring the original folder name.

Still crashing?

Check the exact loader error and your game’s troubleshooting page. If asking for help, include the game and edition, where the crash happens, the exact error and the steps you already tried. A screenshot is more useful than “it does not work”.

For GTA 5, keep the Free Version Setup and Plus Setup instructions separate: their BattlEye requirements differ.
