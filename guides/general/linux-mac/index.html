Use Scooby on Linux & Mac

Compatibility preview. Game support is still being tested. What works and what to expect.

1. Get ready2. Choose your setup3. Start playingGet help

1. Get ready

  1. Download and extract Scooby. Get Scooby-compatibility.zip from Scooby downloads and extract the whole ZIP. Keep all the files together. If you only see the Windows installer, ask support for the compatibility preview.
  2. Check your game works first. Open the Windows version of your game through its usual launcher at least once. It needs to work on its own before you add Scooby.
  3. Open a terminal in the extracted folder. Open the folder containing linux, right-click an empty area and choose Open in Terminal, if your file manager offers it.
New to the terminal? Start here

A terminal lets you run the short commands in this guide. On Steam Deck, use Desktop Mode and open Konsole. Paste a command with Ctrl + Shift + V, then press Enter.

Keep the terminal in the extracted folder that contains linux. If you opened it elsewhere, type cd followed by that folder's full path in quotes, then press Enter. Run Scooby as your normal user, without sudo.

The launch scripts need Python 3.10 or newer. Check with this command:

python3 --version

A result such as Python 3.12.3 is fine. If Python is missing or older than 3.10, install it using your system's supported package manager.

2. Choose your setup

Open the option that matches how you start your game. You only need to follow one.

Linux with SteamI launch my game from my Steam library.
  1. Install Protontricks. Follow the official installation instructions. Installed it through Discover or as a Flatpak? Use the Steam Deck / Flatpak steps instead.
  2. Start your game once with Proton. In Steam, open the game's Properties → Compatibility, select the Proton version you use for the Windows game, then launch it.
  3. Find your game number. Run this command. Look for your game in the list; the number next to it is its App ID. 
    protontricks -l

    Paste the number next to your game. Your launch command will update below.

    Replace APPID in the command below with the number next to your game.

  4. Open Scooby. Copy the command below into your terminal and press Enter. 
    sh linux/launch.sh --runner proton --appid APPID

    The Scooby sign-in window should open. Then continue to Start playing.

Keep using your game's usual Steam entry. Adding Scooby as a separate non-Steam game can put it in the wrong Windows environment.

Advanced: I use a custom Steam data folder

Only use this if you changed the game's Steam compatdata location. Replace the path with the folder containing pfx, not pfx itself.

sh linux/launch.sh --runner proton --appid APPID --compat-data "/path/to/compatdata/APPID"

The App ID field fills in the game number. You still need to replace the example folder path.

Steam Deck / FlatpakI use a Steam Deck, or installed Protontricks through Flatpak.
  1. Use Desktop Mode. On Steam Deck, open Discover, search for Protontricks and install it. Leave SteamOS in its normal read-only state.
  2. Start the Windows game once through Steam. Use its usual Proton version. Keep the extracted Scooby folder open in your terminal.
  3. Find your game's App ID. Run this command and find the number next to your game. 
    flatpak run com.github.Matoking.protontricks -l

    Paste the number next to your game. Your launch command will update below.

    Replace APPID in the command below with the number next to your game.

  4. Open Scooby. Copy this command into the terminal and press Enter. 
    sh linux/launch.sh --runner proton --flatpak --appid APPID

    When the sign-in window appears, continue to Start playing.

Use Desktop Mode with a mouse or trackpad for now. Game Mode, controller navigation and suspend/resume are not yet verified.

My game is on an SD card or another drive

Protontricks may need permission to access that Steam library. Follow its Flatpak access instructions. The Scooby launcher already grants access to its own bin folder for each run.

Linux with Lutris / WineI use Lutris, Rockstar Games Launcher or another Wine setup.

Using Lutris? You can set up a shortcut. Scooby needs the same Windows folder and Wine version as your game.

  1. Open your game's configuration in Lutris. Note the Wine prefix and Wine version. The prefix is the folder containing the game's Windows files.
  2. Add a locally installed game. Name it Scooby, choose the Wine runner, and select linux/bin/ScoobyLoader.exe from your extracted package.
  3. Match the two settings. Use the exact same Wine prefix and Wine version as your game. Leave the bundled DLL files beside ScoobyLoader.exe.
  4. Save and launch Scooby. Once the sign-in window opens, continue to Start playing.
I use Wine directly, without Lutris

Replace both paths with your game's Wine executable and existing prefix folder. Keep the quotes around the paths.

sh linux/launch.sh --runner wine --wine "/path/to/wine" --prefix "/path/to/game-prefix"

The prefix is the folder containing drive_c. It must already be set up and support 64-bit Windows apps. The launcher does not create or repair it. Do not use plain Wine on a Steam Proton prefix.

MacI have a Mac-compatible Wine setup for my Windows game.

Mac support is unverified. You need Python 3.10+ and a Mac-compatible Wine version that runs Windows x64 apps. On Apple silicon, that Wine distribution must also provide the required translation and graphics support.

  1. Confirm your Windows game works first. Find the Wine executable and prefix used by that game.
  2. Open Terminal in the extracted Scooby folder. Replace both example paths, then run: 
    sh linux/mac/launch.command --wine "/absolute/path/to/wine" --prefix "/absolute/path/to/game-prefix"
  3. Continue to Start playing if the sign-in window opens.

Using CrossOver? Follow its instructions to run Scooby in the same bottle as your game. This script does not configure CrossOver bottles automatically. Double-clicking the script without the paths above will not set it up. Proton is Linux-only.

3. Start playing

  1. Sign in to Scooby. Use your account or follow the free-key guide.
  2. Open your game as usual. Use the Steam or Lutris entry you set up above.
  3. Follow your game's loading steps. Open its Scooby guide to check when to load the menu. Timing and game support vary.

Next time: use the same launch command or Lutris shortcut. Close both the game and Scooby before changing Wine or Proton versions.

Something not working?

Pick the problem you see.

“File not found” or the launch script will not open

Open the extracted folder that contains linux, then open a terminal there. Check that linux/bin/ScoobyLoader.exe exists. Extract the whole compatibility ZIP again if files are missing; the standard Windows installer does not include these scripts.

“Python not found” or “Runner not found”

Check python3 --version; you need 3.10 or newer. For Steam, install Protontricks. If you installed it through Discover or Flatpak, follow the Flatpak steps. For Wine, check the Wine executable path.

Scooby cannot find my game

Run the Windows version of the game and check your App ID. In Lutris, Scooby and the game must share the exact same Wine prefix and Wine version. A native Linux game cannot load the Windows menu. If these match, the game may still be incompatible with this preview.

The window is blank, or text is missing

Keep all the runtime DLLs beside the loader and check that your game works with the selected runner. For missing Segoe UI text, add a licensed copy of segoeui.ttf to the same prefix's drive_c/windows/Fonts folder, then restart Scooby. A graphics error may need help with your Wine/Proton setup.

I need to update Scooby or find my settings

Close Scooby, then download and extract the latest compatibility package. Updates are manual; an old package can be blocked by a required minimum version.

Your settings are inside the game's prefix at drive_c/scooby (the Windows path C:\scooby). Each prefix has separate data. If changing prefixes causes an HWID mismatch, follow the HWID reset guide.

The game is running slowly

Compare the game with and without Scooby using the same settings. Performance depends on your graphics drivers, Wine/Proton version and enabled menu features. Close both apps before testing a different runner, and keep the game and loader on the same version.

I need more help / want to check my setup

Add --diagnose to the end of your launch command. It prints a setup report without opening Scooby. This checks local files and launch options; it does not prove that login, graphics, Steam/Flatpak access or game loading will work.

Send Scooby support your OS, game, Wine/Proton version and exact error. Remove private details from reports and never share passwords or license keys.

What works and what to expect

This package runs the Windows x64 loader through Wine or Proton. Login, graphics and in-game loading still need testing on real Linux, Steam Deck and Mac systems. No game is certified yet; the loader opening does not guarantee that its menu will work.

Windows-only cleaner, identifier and kernel-driver tools are unavailable. Native Linux/Mac games cannot load Windows DLLs. Game and anti-cheat restrictions still apply.
