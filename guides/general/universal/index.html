Loader troubleshooting

Choose the message or problem you see. Follow your game’s setup guide alongside these checks.

Loader will not open or closes straight away

  1. Close old loader processes, restart Windows and download the current loader from scoobymenu.cc.
  2. Read antivirus history and download help if the file is missing or blocked.
  3. For missing-runtime or DLL errors, use the Microsoft runtime installers.
  4. If Windows says access is denied, use a folder owned by your Windows account. If your game guide requires elevation, right-click the verified loader and choose Run as administrator.

“Failed to inject module” or “Not injecting”

  1. Check the selected game and edition, then follow the loading order in its setup guide. Do not use one game’s loading steps for another.
  2. For GTA 5, follow the BattlEye setting for your tier: Free Version Setup or Plus Setup.
  3. Read the antivirus detection history. An exclusion is a deliberate exception for a verified file; do not exclude the whole C:\ drive. See your antivirus instructions.
  4. Close both apps and try fresh settings with a backup.
  5. If the error names a folder-access problem, check the actual save path and free disk space. A OneDrive path alone does not prove it is the cause.

“Failed to Find Patterns” or trouble after a game update

Check that the loader and your game build are supported together. A game update can change files the menu expects. Use the current loader and check Scooby’s update announcements before trying repeated loads.

Keep the exact error text and game build for support. Turning off more Windows settings will not repair an unsupported game build.

“Auth Failed”, connection or sign-in errors

Confirm you are using the right account or a current free key. Check your clock and use the connection & SSL checklist. Do not repeatedly reset your HWID for a network error.

If connection attempts time out across different networks, the backend or its hosting provider may be having issues. Hosting outages can be outside Scooby’s direct control. Wait for the service to recover, then try again; a VPN cannot repair a server-side outage.

If the loader specifically reports an HWID mismatch, follow Reset your HWID. Each reset starts a 7-day cooldown; support will not reset it manually.

Scooby folder or subscribed scripts missing?

  • Check both C:\scooby and Documents\Scooby. Documents may be redirected to OneDrive; check the actual location instead of uninstalling OneDrive.
  • For subscribed scripts, verify you are signed in to the expected account and the loader can connect. Restart it after checking your subscription.
  • Test with a clean settings backup before reimporting scripts. Use the game-specific Lua guide for installation and reload steps.

GTA Online errors or BattlEye kicks

Online access and BattlEye requirements differ between Free, Premium and Plus. Read the tier comparison and public-session guide for the mode you use.

If the game reports a graphics or fatal error, note its exact code, verify game files and test the game without Scooby. A kick or error message by itself does not establish its cause or a guaranteed waiting period.

Avoid broad “fixes”

Do not give Everyone full control of your C: drive, uninstall OneDrive or delete all settings as a first step. Use the exact error to identify the file or folder involved. For Windows corruption messages, use Microsoft’s repair guidance or ask for help before changing system permissions.
