Antivirus & Download FAQ

The most common questions people ask before they even get the loader running. Read these first if Windows is blocking or removing your download.

Why is Scooby flagged as a virus?

It is most commonly known as a false positive, which means your PC may automatically flag the mod menu as malware because it doesn't recognise the file or its intentions.

This happens due to the way mod menus are developed, not necessarily because they are malicious.

How can I download the loader?

Simply disable Real-time Protection in Windows Security.

You may also need to temporarily disable your browser's Safe Browsing or Safe Search feature if it prevents the download.

Recommended browsers are Chrome and Firefox.

Why does the Scooby loader delete itself after some time?

This usually happens because the loader hasn't been added as an exclusion in Windows Defender. When Real-time Protection is re-enabled, Windows Defender may automatically remove the loader.

To prevent this, open Windows Security and go to:

Virus & threat protection → Manage settings → Add or remove exclusions → Add an exclusion

Select the Scooby loader. Once it has been added as an exclusion, Windows Defender should no longer remove it automatically.

Free Version Limitations

Free version is invite-only / solo

The free version is limited to invite only sessions or sessions with other modders in GTA Online. Joining a public lobby on the free version will crash.

If you have used Scooby before, delete the C:\scooby folder - the folder, not the loader. If you don't, it will probably crash due to old settings.

Crashing Solutions

Work through these in order - they resolve the overwhelming majority of crashes:

  • Delete C:\scooby. Do this after every Scooby update to avoid conflicts with your old settings
  • Do not use third-party antivirus software (Norton, Avast, Malwarebytes, etc.)
  • Turn off Windows Defender. Avoid Defender Control - just turn it off normally and avoid any issues DC may cause
  • Make sure DirectX runtimes and C++ runtimes are installed
  • Make sure your graphics drivers are up to date
  • Try using a VPN, and make sure it has no built-in antivirus or anti-malware settings. Cloudflare works for most users
  • Make sure Date & Time is synced in Windows settings
  • If all of the above fails and you are still crashing, it is probably your user permissions - create a new Windows user with admin rights

Free users

Make sure you are following the injection instructions properly. Almost every issue comes from skipping steps. The guides exist for a reason - if you want to play without the restrictions, the Premium Plus version gives you access to everything. Otherwise, use the limited free version as documented.

Universal Troubleshooting

Fixes for the specific errors people hit most often. This list is updated regularly - check back after an update before opening a ticket.

Not injecting

  • Make sure you have disabled BattlEye in the Rockstar Launcher. If you launch through Steam or Epic, disable it there too with the launch argument -nobattleye
  • Exclude the Scooby application and its folder in Documents from Windows Defender. Third-party antivirus can still cause issues even when fully disabled
  • Run Scooby as Administrator
  • Delete the Scooby folder in your C:\ drive
  • Remove OneDrive - it can cause permission issues in the Documents folder
  • Verify your system files: open CMD as Administrator and run sfc /scannow
  • Make sure your C: drive and Scooby folder have Full Control in their Properties → Security settings

"Failed to inject module. Try disabling your Anti-Virus."

A few different things cause this error. Follow these steps correctly and it should stop appearing:

  • Make sure you are using the correct Windows user profile with Administrator privileges, and always run the Scooby loader as Administrator
  • Move the Scooby loader to your Desktop, then add both the loader and your C: drive folder to your antivirus exclusions
  • If you have OneDrive enabled, fully unlink and uninstall it

You can tell OneDrive is getting in the way if you can't find the Scooby folder in your normal Documents folder, or if the path shown in your antivirus exclusions contains "OneDrive".

Crashing on inject

  • Exclude the Scooby application and its folder in Documents from Windows Defender. Third-party antivirus can still cause issues even when fully disabled
  • Check the log to see if you are getting Failed to Find Patterns - if so, follow the Failed to Find Patterns guide in our Discord
  • Make sure HDR is disabled in Windows Display Settings
  • Verify your GTA game files
  • Delete the Scooby folder in your C:\ drive
  • Verify your system files: open CMD as Administrator and run sfc /scannow

Loader not opening, or "Auth Failed" error

  • Use a VPN - https://one.one.one.one/
  • Disable or remove any third-party antivirus

"GTA detected a fatal error"

Most of the time this is not caused by Scooby, but by faulty game files or something else on your system. Look up the specific error code shown (for example ERR_GFX_STATE) - it will point you to the actual cause.

Subscribed scripts not showing up

Use a VPN - https://one.one.one.one/

Why am I getting desync-kicked by BattlEye while using Scooby?

The reason for the desync-kick is that you are joining public sessions as a non-host, which causes BattlEye to remove you from the session.

This happens because you are playing GTA Online with BattlEye disabled while other players have it enabled.

To prevent it, start your own sessions as the host. You will then be able to play normally with non-modders who have BattlEye enabled. In the menu, go to:

Session Tab → Session Starter → Invite-Only Session or New Public Session

If you want other players to join, enable the Advertise Session function in the host toolkit, or simply invite your friends. See How To Host Public Sessions with Scooby for the full walkthrough.

We also have a BattlEye bypass that lets you join anyone, including random public sessions - all the information on that is on the GTA 5 product page.

Getting BattlEye kicked even without Scooby running

You most likely joined a public lobby where you were not the host and got kicked by BattlEye while using Scooby. You will need to wait 12-24 hours for the kick to go away.

Until then, stick to lobbies where you are the host, or where another BattlEye-disabled player is the host.

Scooby folder not in Documents

Check your C:\ drive for it. It falls back there if permissions fail in Documents - usually because of OneDrive.

Connection or SSL Errors

If you get connection errors trying to load the website or the loader, it is because your ISP is blocking the connection to the servers.

USE A VPN

Cloudflare is usually good for most users, or you can use Proton.

If you are still getting errors while connected to a VPN, it probably means you need to use a better VPN.

Resetting Your HWID

If you have changed hardware or are getting an HWID mismatch, reset it from the portal:

  • Go to scoobymenu.cc/portal and log in
  • Open the dropdown menu in the top right
  • Click "My Profile"
  • Scroll down to Hardware ID
  • Click "Reset HWID"

On cooldown?

If you are on cooldown then you need to wait - the reset cannot be forced through early.

Use Scooby on Linux & Mac

Scooby is a Windows application, but it runs on Linux and Mac through a Windows compatibility layer. The trick is making sure the loader and the game live in the same prefix - otherwise the loader cannot see the game to inject into.

Linux

  • Install Lutris
  • Install the Rockstar Games Launcher through Lutris and let it update to the latest version
  • Install GTA V through the Rockstar Games Launcher, inside Lutris
  • Add ScoobyLoader.exe to Lutris as a pre-installed game, and set its WINE prefix to the same prefix the Rockstar Games Launcher uses
  • Copy segoeui.ttf into that prefix's Windows\Fonts folder
  • Launch ScoobyLoader.exe through Lutris and play as normal

Why the font matters

Segoe UI is a Windows font that WINE does not ship. Without it the menu can render with missing or broken text, so copy segoeui.ttf into the prefix before you launch.

Performance

Scooby itself does not really affect performance. If the game runs badly, that is the compatibility layer rather than the menu.

Try different WINE or Proton versions - performance varies a lot between builds, and switching runner version is usually the single biggest win.

Mac

The same approach works on Mac through CrossOver, and other tools for running Windows apps on Mac will work the same way. Set it up exactly as above: game and loader in the same bottle/prefix, with the Segoe UI font added.

Heads-up on Mac performance

GTA 5 itself runs poorly on Mac in our testing, including on M4 Pro and M4 Pro Max. It does run - it is just not a great experience. That is the game under translation, not a Scooby issue, and there is nothing on our side that changes it.
