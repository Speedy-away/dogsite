Start here

A security warning needs checking. A mod menu can trigger detections because of what it does, but that does not prove every warning is a false positive. Check the exact detection and download source before changing protection.

Download or file missing?

  1. Start at scoobymenu.cc and use its loader download. Avoid reuploads, adverts and files sent by strangers.
  2. If your browser blocks the official loader download, open Downloads and choose Allow (called Keep or Keep anyway in some browsers).
  3. If the file disappears, open your antivirus detection history or quarantine. In Windows Security, this is Protection history. Write down the file path and detection name.
  4. If you believe a detection is incorrect, request a review through the antivirus vendor. Only consider a narrow exclusion for a file you have independently verified and decided to trust.

Which antivirus is protecting my PC?

  1. Open Start, type Windows Security, and open it.
  2. Select Virus & threat protection → Manage providers under “Who’s protecting me?”.
  3. Read the active antivirus name, then choose it below. Changing Defender settings will not change another antivirus.

Choose your antivirus

Open only the product you use. These instructions cover Windows; app versions and translations can change the labels. Personal devices need an administrator account. If settings are managed by your organization, contact its administrator.

Keep changes small

An exclusion skips security checks for the selected item. Use an exact file path, not an entire drive, Downloads folder or every .exe. Temporary pauses reduce protection too: use them only to diagnose a trusted app, then turn protection back on. Leave the firewall enabled.

Microsoft DefenderWindows Security / Windows Defender+

Add or remove an exclusion

  1. Open Windows Security → Virus & threat protection → Manage settings.
  2. Scroll to Exclusions → Add or remove exclusions. Choose Add an exclusion → File and select the exact trusted file.
  3. Check the saved path. To undo the exception, select it and choose Remove.

Temporarily pause real-time protection

  1. On the same Manage settings page, switch Real-time protection off and approve the prompt.
  2. Run only the short diagnostic you intended. Return here and switch it On afterward; Defender can also turn itself back on automatically.

If the control is unavailable, check the active provider or administrator policy. Use Microsoft’s current guidance ↗ for your version; do not use registry hacks or third-party “Defender disabler” tools.

NortonNorton 360 / Norton AntiVirus+

Add or remove an exclusion

  1. Open Norton, then Security → Scans → Open → Exclusions.
  2. Choose Add / Add Exclusion, browse to the specific trusted file and confirm with OK → Add.
  3. Remove an old exception using the X beside it. If your layout differs, follow Norton’s exclusions guide ↗.

Temporarily pause Auto-Protect

  1. In the taskbar notification area, right-click the Norton icon. You may need the hidden-icons arrow.
  2. Choose Disable Auto-Protect, pick the shortest suitable duration and confirm. Leave Firewall enabled.
  3. When finished, right-click the icon and select Enable Auto-Protect.

Official Norton pause instructions ↗ · Uninstall Norton instead →

AVGAVG AntiVirus FREE / Internet Security+

Add or remove an exception

  1. Open AVG and select Menu → Settings → General → Exceptions → Add exception.
  2. Review the risk notice, then choose File / Folder. Browse to the trusted file and save with Add.
  3. To remove it later, return to Exceptions and use the X beside the entry.

Temporarily pause File Shield

  1. Open AVG and select Computer.
  2. Switch File Shield off, select a short duration and confirm with OK, stop.
  3. Switch File Shield back on when your check is complete. This pauses one component; other shields still work.

Official AVG exceptions instructions ↗ · Uninstall AVG instead →

AvastFree Antivirus / Premium Security / Avast One+

Add or remove an exception

  1. Open Avast and choose Menu → Settings → General → Exceptions → Add exception.
  2. Read the notice, select File / Folder, browse to the trusted file and choose Add.
  3. Remove an exception later with the X beside it. Avast One can use different menus; use the Avast One link in the official article.

Temporarily pause shields

  1. Right-click the Avast tray icon and open Manage Shields (older releases may call it Avast shields control).
  2. Choose the shortest suitable interval, confirm, then restore the shields immediately afterward. Avoid the permanent-off option.

Official Avast pause instructions ↗ · Uninstall Avast instead →

McAfeeLiveSafe / Total Protection+

Add a file exclusion

  1. Open McAfee and go to My Protection → Device → Real-Time Scanning.
  2. Under Excluded Files, choose Add file, then select the specific trusted file. McAfee checks it before allowing the exception.
  3. Review this list after an app update: a changed file can lose its exclusion. To undo an entry, use its removal option.

Temporarily pause scanning

In versions that expose the control, open Real-Time Scanning → Turn off, choose a brief automatic resume time, and confirm. Turn it back on immediately afterward. Newer plans can differ; follow the instructions for your installed version.

McAfee’s real-time scanning reference (older interface) ↗ · Current file-exclusion help ↗ · Uninstall McAfee instead →

BitdefenderAntivirus Plus / Internet Security / Total Security+

Add a file exception

  1. Open Protection → Antivirus → Open → Settings → Manage Exceptions.
  2. Select Add an Exception, browse to the specific trusted file, choose the Antivirus scope and save.
  3. Review the scope; other modules can still block the app. Remove unused entries from Manage Exceptions.

Temporarily pause antivirus

Under Protection → Antivirus → Open → Advanced, switch Bitdefender Shield off. Choose Until system restart rather than permanently, then turn it back on manually after the check. This does not pause every Bitdefender module.

Official exceptions guide ↗ · Official pause guide ↗

MalwarebytesDevice Protection & Antivirus+

Add an item to the Allow list

  1. Open Malwarebytes and select Detection History → Allow list → Add item.
  2. Choose the trusted file or app, review the notice and save.
  3. Remove unused rules using the trash icon in the same list.

Temporarily stop Malwarebytes

For a brief diagnostic of a trusted app, right-click the Malwarebytes tray icon and choose Quit Malwarebytes. Approve the Windows prompt if shown. Reopen Malwarebytes as soon as the test finishes and verify that protection is active.

Official Allow list guide ↗ · Official troubleshooting guide ↗

ESETHome and small office Windows products+

Add a file exclusion

  1. Open ESET and press F5 for Advanced setup.
  2. Open Scan → Performance Exclusions → Edit (some versions use Scans → Exclusions).
  3. Choose Add, browse to the exact trusted file, and confirm the dialogs. Remove it later from the same list.

Temporarily pause protection

Open Setup → Computer protection → Pause Antivirus and antispyware protection. Choose a short interval and apply it. Finish the diagnostic, then choose Enable Antivirus and antispyware protection.

Prefer Microsoft Defender?

For a simpler Windows setup, you can use the built-in Microsoft Defender Antivirus instead of keeping a separate consumer security suite. Uninstall software you no longer need, restart, then verify Defender is active. Keep Windows and its security updates current.

Resource use depends on the product, hardware, enabled features and current scan activity. Check Task Manager → Processes for CPU, Memory and Disk usage before deciding; removing an antivirus does not guarantee an FPS improvement.

Use the normal uninstaller first. Save your work and close the antivirus window. On Windows 11, go to Settings → Apps → Installed apps; on Windows 10, use Settings → Apps → Apps & features. Microsoft’s uninstall help ↗

Uninstall NortonWindows · remove, restart, check Defender+
  1. Press Win + R, enter appwiz.cpl, select Norton 360, then choose Remove / Uninstall.
  2. In the Norton removal window, choose Uninstall / Remove, confirm, and let it finish. Choose removal rather than repair or reinstall.
  3. Restart Windows, then complete the Defender check below.

If normal removal fails, use the Norton 360 Remover linked in Norton’s instructions. Select removal only. Norton Private Browser is a separate app. Official Norton removal instructions ↗

Uninstall AVGWindows · remove, restart, check Defender+
  1. Find AVG in the installed-apps list and choose Uninstall. Approve the Windows permission prompt.
  2. In the AVG removal window, choose Uninstall / Remove, confirm, and let it finish. Choose removal rather than repair or reinstall.
  3. Restart Windows, then complete the Defender check below.

If normal removal fails, follow AVG’s official Uninstall Tool instructions; the tool may require Safe Mode. Official AVG removal instructions ↗

Uninstall AvastWindows · remove, restart, check Defender+
  1. Find Avast in the installed-apps list and choose Uninstall. Approve the Windows permission prompt.
  2. In the Avast removal window, choose Uninstall / Remove, confirm, and let it finish. Choose removal rather than repair or reinstall.
  3. Restart Windows, then complete the Defender check below.

If normal removal fails, use the official Avast Uninstall Tool instructions, which can use Safe Mode. Official Avast removal instructions ↗

Uninstall McAfeeWindows · remove, restart, check Defender+
  1. Find McAfee in the installed-apps list and choose Uninstall. Approve the Windows permission prompt.
  2. In the McAfee removal window, choose Uninstall / Remove, confirm, and let it finish. Choose removal rather than repair or reinstall.
  3. Restart Windows, then complete the Defender check below.

If normal removal fails, follow McAfee’s MCPR removal instructions. WebAdvisor or other separately listed apps may need their own uninstall. Official McAfee removal instructions ↗

Uninstalling does not cancel a subscription

Check renewal and billing settings separately in the vendor account. Do not download removal utilities from adverts, mirrors or “PC cleaner” sites. Use the official instructions linked above.

After uninstalling: check your protection

  1. Open Windows Security → Virus & threat protection → Manage providers. Confirm Microsoft Defender Antivirus is the active antivirus.
  2. Go back to Manage settings and check Real-time protection is on. Update protection definitions and run a Quick scan.
  3. If Defender stays off, restart again and check for another installed antivirus. Use the removed vendor’s official removal help if it still appears. On managed devices, ask the administrator.

Microsoft: check the active provider ↗. Defender normally returns to active mode after the other antivirus is removed.

Still blocked or unsure?

Stop and keep the detection details rather than repeatedly bypassing protection. For a suspected false positive, ask the antivirus vendor to review the file. For a loader error, include its exact wording and your antivirus name when asking for help. Never share a key, password or recovery code.
