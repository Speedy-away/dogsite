FiveM · Scooby Wiki

How to Inject

Timing is the single biggest factor in whether the injection works. Do it at the right moment and it is reliable every time.

Best way to inject

Inject at the FiveM main menu, or while the server is loading its resources and assets (the loading screen you get after picking a server).

This is the most reliable point and the method we recommend.

Step by step

  • Open the Scooby loader and sign in
  • Select FiveM
  • Launch FiveM
  • Click Inject at the main menu, or once you have joined a server and it is loading resources/assets
  • Wait for Scooby to finish loading, then open the menu

Already in a server?

You can still inject while you are already in a server and in game - it is supported and it works. The main menu / resource loading screen is simply the more reliable moment, so use that when you can.

Injection not working?

Make sure your antivirus is fully disabled and the loader is excluded from Windows Defender, then try again from the main menu. If it still fails, work through Universal Troubleshooting in the General tab.
