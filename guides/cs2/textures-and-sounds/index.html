Custom textures & sounds

Import images and WAVs, edit a skin design, and apply custom textures or sounds to the right weapons, teams and maps.

CS2 Custom Textures and Weapon Sounds

Import texturesSkin editorTexture exportsMap materialsWeapon soundsSound packs

Import and apply an image

  1. Go to Custom > Textures. If you see Open Textures, choose it to open the standalone window. Select Open folder. Copy a PNG, JPG or GIF into C:\scooby\CS2\textures.
  2. When the image appears, select a target. For weapons, choose All, CT or T and the weapons to edit. Use the 3D preview to check the selected weapon.
  3. When the editor shows a batch or both teams, select Apply to N weapons to commit the draft. Use Default texture or Remove texture to restore an individual target where offered.

The Skin editor, texture exports and map material presets are documented for development builds. Check the feature list for availability.

Design and save an editable skin

  1. Open Skin editor. Start with an image, a solid color or a two-color gradient. Add up to four stickers and adjust their placement, tint and opacity. Choose Keep full image to preserve the source proportions when baking.
  2. Choose Save project to keep an editable copy in C:\scooby\CS2\texture-projects. Keep the entire project folder together. Select its project.json in Open project to resume editing.
  3. Choose Bake texture, then Use baked texture. Apply the resulting texture to the selected scope.

Export UV templates and dump textures

  1. Under Weapons > Export, choose Export weapon UV template for the previewed firearm or Export all weapon templates for the set.
  2. Open edit-me.png in an image editor. Place uv-guide.png above it as a transparent guide. Hide the guide before saving the design, then import the edited PNG and check the 3D fit.
  3. On a texture tab, use Export > Dump selected texture to save the selected image as PNG. GIFs export one PNG per frame and a texture.json with frame delays. Select Open dumper folder to find the results under C:\scooby\CS2\dumper.

Change map materials and share a preset

  1. Under Custom > Textures > Map materials, choose Global or a map. An enabled map preset takes priority over Global.
  2. Assign a texture to an individual material, a category or the whole map. The most specific rule wins. Use the Object inspector and Preview applied textures to compare supported props.
  3. Under Map projects, choose Save project to export the selected preset. Share the complete folder from C:\scooby\CS2\map-texture-projects, including its image files.
  4. To use a shared preset, choose Open project and select map-project.json. Check the destination map and choose Apply opened project. Use Undo preset edit to reverse that edit.

Assign one WAV

Open Custom > Sounds > Per-weapon sounds and choose Open folder. Copy a WAV into C:\scooby\CS2\sounds. Select a team, weapon and action, then pick your file under Audio. Use Test sound to audition it, or choose Game default to return to stock audio.

Set up a weapon sound pack

Open Custom > Sounds > Sound packs. Available builds can include CS:GO Classic, CS:GO Legacy, CS: Source and CS 1.6. Select a pack, choose the team and weapon scope, then use Test sound before selecting Apply sound pack.

For your own pack, choose Open custom packs folder and put its WAVs in a named subfolder. Use names such as ak47_fire.wav, ak47_reload.wav, ak47_draw.wav or ak47_empty.wav. A pack applies only matching actions. Use Restore game sounds to reset the selected scope.
