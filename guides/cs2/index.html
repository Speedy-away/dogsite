Counter-Strike 2 guide

Setup, injection, and fixes after updates.

On this page Requirements How to Inject Features Not Working

Requirements

Before running Scooby on CS2, make sure the VC Runtimes are installed:

Required Software:

VC Runtimes (all-in-one package):

https://www.techpowerup.com/download/visual-c-redistributable-runtime-package-all-in-one/

Or install these two directly from Microsoft:

https://aka.ms/vc14/vc_redist.x86.exe https://aka.ms/vc14/vc_redist.x64.exe

Install those and restart your PC.

Still having problems? See Universal Troubleshooting, Crashing Solutions and Connection or SSL Errors in the General tab.

How to Inject

There are two ways to get Scooby into CS2. Pick whichever suits where you are.

Load button (easiest)

Pressing Load will close CS2, reopen it and inject automatically. You do not need to do anything else - just let it restart the game.

Manual inject

If CS2 is already loaded and you do not want it restarted, use manual inject instead. You must be sitting on the main menu when you do it.

  • Have CS2 open and sitting on the main menu - not in a match
  • Choose manual inject in the loader
  • Wait for Scooby to load, then open the menu in game

Injection failing?

Make sure your antivirus is fully disabled and the loader is excluded from Windows Defender. If it still will not inject, work through Universal Troubleshooting in the General tab.

Features Not Working

If Scooby loads but none of the features do anything, that almost always means one thing:

CS2 HAS BEEN UPDATED AND SCOOBY NEEDS UPDATING TO MATCH

Valve patches CS2 regularly, and every patch moves things around internally. Until Scooby is rebuilt against the new version, the menu will open but the features will not work.

How long does an update take?

It varies. Sometimes it is within an hour of the CS2 update, sometimes a day, sometimes up to about five days - realistically, whenever we have time to get to it.

The CS2 menu is completely free, so it sits behind the paid products in the queue. We would rather be straight with you about that than promise a turnaround we cannot always hit.

What to do in the meantime

There is nothing to fix on your end - reinstalling will not help. Check the Discord for the current status, and update the loader once the new build is announced.
