Features Not Working

If several features stopped after a CS2 patch

Check the Scooby Discord for compatibility and release announcements. After a matching build is announced, close CS2 and load it again with the current Scooby Loader.

When will the update arrive?

Timing depends on the changes in the game patch. Check the release announcement for your build before retrying.

If one feature or preview fails

  1. Check the feature list for availability. Controls under Development build may differ from the ones in your loader build.
  2. Check the active profile, feature toggle, keybind and target. For models, check Library and package status. For textures and sounds, verify the target and scope.
  3. If you report the issue, include the CS2 build, Scooby version, map or mode, the feature and exact menu or loader message.

If your startup profile fails to load

Open Settings > Config > Load and choose a valid profile to resume auto-save. Scooby keeps the old startup file in a timestamped .bak next to default.json. Restart Scooby after a confirmed config reset.

If the loader reports an error before the menu opens, start with the loading guide.
