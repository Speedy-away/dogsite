Custom Models

Install compatible CS2 models from Repo or import your own. Use Library to preview and equip them, or use Model swapping for built-in assets.

Download from Repo

  1. Open Custom > Repo. Search by name or filter by category. Development builds have a dedicated First-person arms category.
  2. Preview a package, choose Download, then confirm Download and install. Some local variants use Install.
  3. When installation finishes, choose Open in Models. For a multi-model package, use Choose model and Browse this model to open the exact variant in Library.

The Repo catalog depends on your Scooby build. If the card still shows its earlier status after installation, select Refresh.

In development builds, Library > Random > Download Random Models opens a review of compatible weapon and equipment packages. Check the selection, download size and disk estimate before queuing it. After installation, Random Models rerolls the saved pools.

Find the CS2 game folder

In Steam, right-click Counter-Strike 2 and select Manage > Browse local files. Open game\csgo from that folder. The default location is below.

C:\Program Files (x86)\Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\

Compiled models use .vmdl_c files. Keep the accompanying materials, textures and animations at their original paths.

Import a compiled package

  1. Extract the archive and find the folder that contains the original resource trees, such as characters\models, models\weapons and materials.
  2. Open Custom > Library and choose the matching category. Open its gear menu and choose Import folder, or Import weapon folder where shown.
  3. Select the extracted folder. Once the import finishes, open the model in Library. Use Sync to rescan installed packages after file changes.

For manual installation, close CS2 and copy the extracted resource trees into game\csgo at their original relative paths. If the archive has a game\csgo wrapper, copy the contents inside it. Restart CS2, load Scooby and rescan Library.

Preview and equip

Open Custom > Library, select the model, check its preview and pick a target and scope. Click Equip model to save the assignment. Use Unequip model to clear the selected assignment.

Teammates, enemies and agents

Under Library > Players, select Teammates or Enemies and a team, then equip the model. Use the gear menu for individual agent rules. In builds with model pools, use Add to pool and Remove from pool to manage variants for the selected group.

Your body and first-person arms

Under Library > Self, choose CT or T. Set Self model in the gear menu to choose your body or First-person arms. A separate arms assignment takes priority over the matching arms supplied by a body package.

Weapons, knives and equipment

Open the appropriate Library category, choose the item and equip a compatible model. Keep its first-person and world resources together. In builds with weapon scopes, choose My weapons, Other players or Dropped items. Use Both when the team picker offers it and you want a held-item assignment for CT and T. Dropped-item assignments use their own scope.

Import weapon packages with animations, sounds and icons

In development builds, use Library > Weapons > Import weapon folder with the complete extracted package. Keep its compiled model, animation and sound mapping files, WAVs and compiled .vsvg_c icon together. See Custom > Guide > Weapon packages for the in-game walkthrough.

Compatible animation tracks apply to the actions supplied by the package. Sounds set explicitly in Custom > Sounds take priority over package audio. A validated icon can appear in your weapon selection HUD and matching killfeed entries.

Swap built-in CS2 models

In development builds, select Custom > Model swapping > Open Model swapping or press F8 to open the standalone window. Rebind the shortcut under Settings > Hotkeys.

  1. In Set up swap, choose a Target and Replacement. Select Preview replacement to open the Preview tab, then use Show original to compare them.
  2. Choose Saved texture to see the target's assigned texture on the replacement, Stock materials for its original finish, or Try a texture to audition an image in the preview.
  3. Set Apply to for your held items, other players' items or dropped items. Player bodies have separate choices for your own model and other players' models. Choose Save swap to apply it.

In Saved swaps, use Restore original to turn the rule off. A matching Library assignment resumes if one exists. Use Enable swap to reapply the rule or Remove to delete it.

Clear a Library assignment

Select the same category, model, team and scope and choose Unequip model. Check for a remaining team, agent or pool assignment if you still see a replacement.

Troubleshoot models and previews

  • Model missing. Verify the original folder paths and compiled files, choose the matching category and use Sync to rescan.
  • Needs attention. Hover over the Library tile or open its package details. Check for missing dependencies or incompatible assets. If the game rejects a newly installed resource, restart CS2 and try again.
  • Wrong model or hands. Check the selected scope, the explicit arms assignment and the package's first-person support. Compare with the original model to isolate a package issue.
  • Only one package has problems. Include its name, target, resource path and the exact package status when reporting it. If several features stopped after a patch, follow the CS2 troubleshooting guide.
