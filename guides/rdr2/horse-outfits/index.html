Horse Outfits

Customize your horse's equipment, install saved horse outfits, and keep a reusable JSON preset.

Horse Outfits

The horse outfit editor works on your active, saddle, or recent horse. Its saves apply equipment to an existing horse, so have the horse you want to customize available before loading a preset.

Horse outfit folder and menu

C:\scooby\RDR2\outfits\Horse
Self → Outfits → Outfits → Horse
Choose Editor, Saved Outfits, or Presets inside the Horse tab. This is part of the Premium outfit editor.

Choose your horseInstallSave and shareTroubleshooting

Choose and customize your horse

  1. Mount or call the horse you want to edit. The editor can keep targeting your saddle or recent horse after you dismount.
  2. Open the Horse → Editor tab and select Refresh Horse.
  3. Wait for the compatible equipment scan to finish.
  4. Adjust the available items and textures, or open Presets to try a built-in horse appearance.

Use a matching horse model when possible. Equipment and coat compatibility can differ between models. Loading a saved horse outfit applies its components to the current target; it does not spawn a horse or change that horse into the saved model.

Install a shared horse outfit

  1. Get a horse outfit exported by Scooby RDR2 and extract the archive if necessary.
  2. Paste C:\scooby\RDR2\outfits\Horse into File Explorer. Copy the .json directly into that folder.
  3. Open Horse → Saved Outfits and clear the saved-outfit search if needed.
  4. Select the file and use Load Selected. If Apply saved horse outfit when clicked is enabled, selecting the row loads it immediately.
C:\scooby\RDR2\outfits\Horse\
    MyHorseOutfit.json

Use the horse editor's own export format. Player outfit JSON files and unrelated legacy horse files are not interchangeable with these saves.

Save and share your horse's equipment

  1. With the target horse available, open Horse → Saved Outfits.
  2. Enter a Horse outfit name, then select Save Current.
  3. Alternatively, use Quick Save for an automatically generated name.
  4. Back up or share the JSON from outfits\Horse, including the horse model you used. Choose a new name when you want to keep an earlier version.

If your horse outfit does not work

  • No horse found: mount or call your horse, then use Refresh Horse.
  • No compatible slots yet: let the equipment scan finish before editing.
  • File is missing: keep it directly in outfits\Horse, confirm the .json extension, clear the search, and reopen Saved Outfits.
  • Unsupported horse outfit format: ask for a save made with the Scooby RDR2 horse editor. Renaming another file does not convert it.
  • Appearance differs: try the same horse model the author used. Built-in legacy presets apply a compatible coat base, while native saves retain individual equipment components.
