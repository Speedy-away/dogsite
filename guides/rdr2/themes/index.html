Guides/Red Dead Redemption 2/Customization

Themes

Install saved appearance settings, add ListUI image themes, and save your own RDR2 menu design.

Themes

RDR2 has two separate theme workflows: saved appearance settings in JSON files, and ListUI image folders. Check what your download contains before choosing its destination.

Theme locations

Saved appearance JSON: C:\scooby\RDR2\theme
ListUI images: C:\scooby\RDR2\images\ListUI
Start in Settings → Appearance.

JSON themesListUI imagesSave and restoreTroubleshooting

Install a saved JSON theme

  1. Get a theme made for Scooby RDR2 and extract the download.
  2. Copy its .json file directly into C:\scooby\RDR2\theme. The folder name is theme, without a trailing “s”.
  3. Open Settings → Appearance → Themes.
  4. In Saved Themes, select Refresh, select the theme from the library, and select Load.
C:\scooby\RDR2\theme\
    MyTheme.json

Keep the JSON directly in the theme folder; this library does not scan theme subfolders. If the theme refers to custom images, keep those files available at the paths specified by the author.

Install a ListUI image theme

  1. Open Settings → Appearance → ListUI, then the Images controls.
  2. Select Open Image Folder, or open C:\scooby\RDR2\images\ListUI in File Explorer.
  3. Copy the entire image-theme folder there, preserving its slot filenames.
  4. Select Reload Images, then use Next Theme until your theme is selected.
  5. Enable the image slots you want, such as Header and Menu Background. Check Image Opacity if they appear invisible.
C:\scooby\RDR2\images\ListUI\
    MyTheme\
        header.png
        background.png
        selector.png

Supported slot-image extensions are .gif, .png, .jpg, and .jpeg. Slot names matter: preserve names such as header, background, and selector. Loose slot images can also live directly in the ListUI folder.

Save your design or restore defaults

  1. Adjust the appearance settings, then open Themes → Saved Themes.
  2. Enter a new Theme name without the extension and select Save Current.
  3. Find the resulting JSON in C:\scooby\RDR2\theme. Use a different name to keep an older design; saving with the same name replaces that file.
  4. When sharing, include any separately referenced images or ListUI image folder. The JSON save does not bundle those image files for you.

Apply Preset changes the built-in color palette while keeping your layout and images. Restore Scooby Defaults restores ClickUI appearance settings after confirmation without deleting saved theme files.

For a broader backup of your menu settings, use a config profile as well as copying the theme and image files.

If your theme is missing or incomplete

  • JSON theme not listed: check the singular theme folder, remove any extra archive wrapper folder, and refresh.
  • ListUI images missing: check the selected native theme, slot filenames, image toggles, and opacity, then reload images.
  • Only part of the design changes: load the appearance JSON and select the image theme separately when the author supplies both.
  • Load fails: restore the original JSON and confirm it is for Scooby RDR2. GTA 5 theme bundles use a different workflow.
