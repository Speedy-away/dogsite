Guides/Red Dead Redemption 2/Customization

Outfits

Install shared JSON outfits, edit your wardrobe, and save clothing presets for your RDR2 character.

Outfits

Saved Outfits keeps your character's model and equipped clothing in readable JSON files. Use an outfit made for RDR2 and the character or Online gender you intend to use.

Outfit folder and menu

C:\scooby\RDR2\outfits
Self → Outfits → Outfits → Saved Outfits
The outfit editor is a Premium feature in this build. Its saved files use .json.

Install and load a shared outfit

  1. Download a Scooby RDR2 outfit from its author or the Scooby community. Extract it if it arrives in an archive.
  2. Paste C:\scooby\RDR2\outfits into File Explorer and copy the outfit's .json file directly into that folder.
  3. Open Self → Outfits, choose the Outfits tab, then open Saved Outfits.
  4. Select Refresh and use Clear Search if needed.
  5. Select the outfit and use Load Selected Outfit. If Apply outfit when clicked is enabled, selecting it applies it immediately.
C:\scooby\RDR2\outfits\
    MyOutfit.json
    Horse\
        MyHorseOutfit.json

Player outfits go directly in outfits. Files inside outfits\Horse belong to the separate horse outfit editor.

A saved player outfit can restore its saved model as well as clothing. Save your current outfit before trying another, and keep Story Mode and Online presets clearly named.

Edit your wardrobe or use a preset

  1. Open Wardrobe and select Refresh Wardrobe after changing models.
  2. Wait for the compatible clothing scan to finish. Adjust the available clothing items and textures in each slot.
  3. For a ready-made look, open Presets. Choose the appropriate male/female folder, or use Use Detected Model Folder for your current multiplayer model.
  4. Apply a compatible preset, then return to Wardrobe to make any changes.

Save and share your own outfit

  1. Open Saved Outfits after finishing your clothing changes.
  2. Enter an Outfit name and select Save Outfit. Scooby adds the JSON extension.
  3. Use Quick Save if you want an automatically generated name.
  4. Find the saved file in C:\scooby\RDR2\outfits. Copy it to a backup or share it with the intended character/model details.

If an outfit fails to appear or apply

  • Missing file: put the JSON directly in the outfits folder, refresh, and clear the search.
  • Unsupported or broken file: restore the original download or request a Scooby RDR2 export. A GTA outfit, XML file, or renamed file is not automatically compatible.
  • Wrong model or gender: use a preset for the intended character. Some incompatible Online outfits are rejected instead of applied.
  • No clothing slots: refresh the wardrobe and wait for the scan. Some models expose fewer compatible items.
  • Feature locked: check that your RDR2 license includes the Premium outfit editor.
