Before Launching Scooby

Red Dead Redemption 2 does not use BattlEye, so it does not matter whether you leave it on or off.

Get these sorted before you launch anything:

  • Make sure your graphics drivers are up to date
  • Install all runtimes and DirectX runtimes - just choose to install them when running the Scooby Installer, then restart your PC afterwards
  • Disable Windows Defender. Turn it off normally - do not use Sordum / Defender Control, it causes issues for some people and turning Defender off manually removes that possibility of errors
  • If you have any third-party antivirus installed (Norton, Avast, Malwarebytes, etc.) you need to uninstall it. These still cause issues even when they are "off"
