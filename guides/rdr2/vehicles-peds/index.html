Vehicles, Peds & Animals

Use the model libraries to spawn wagons, characters, and animals, or change your own character model.

Vehicles, Peds & Animals

RDR2's spawners use models already available in the game. Open a library, search for a model, preview it, and use its spawn action. A ped is a character model; spawning one creates another character, while Model Changer changes your own.

Where to find the spawners

World → Spawn → Vehicle / Ped / Animal
For your own character: Self → Outfits → Model Changer.

Spawn a wagon or other vehicle

  1. Load into the game and open World → Spawn → Vehicle.
  2. Choose All Vehicles and search the Vehicle Library. A favorites-only view will show a smaller list.
  3. Select an entry and check its name and model in Selected Vehicle.
  4. Use Preview to inspect it, then Spawn Vehicle to create it near your character. Leave enough open space for larger vehicles.

This is a model-spawning workflow. The supplied RDR2 build does not provide GTA 5's saved-vehicle JSON/XML/INI import workflow, so copying GTA vehicle presets into a new RDR2 vehicles folder will not install them.

Spawn a character or animal

  1. Choose World → Spawn → Ped for characters, or World → Spawn → Animal for animals.
  2. Select a category, or use All Peds / All Animals. Search for the model you want.
  3. Select the model and review the available spawn options.
  4. Use Spawn Ped or Spawn Animal. Choose one model at a time so you can check the result.

To customize equipment on an active or owned horse, use Horse Outfits. An outfit file changes equipment; it is not a replacement for spawning or acquiring a horse.

Change your own character model

Open Self → Outfits → Model Changer and choose an available model. Save your current outfit first if you want a file to return to later.

After changing models, open Outfits → Wardrobe and select Refresh Wardrobe. Clothing slots and compatible items depend on the selected model; wait for its scan to finish.

If a model is missing or will not spawn

  • Empty library: clear the search and switch from Favorites to the full category.
  • Nothing appears: wait until your character is fully loaded, move to an open area, and try a standard model from the library.
  • A downloaded model pack does not appear: these libraries do not install custom game assets. Follow that pack's RDR2-specific requirements and installation instructions.
  • A GTA 5 or RedM download fails: get a version explicitly made for Scooby RDR2. A similar filename or extension does not make the content compatible.
