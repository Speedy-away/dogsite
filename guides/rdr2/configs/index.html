Configs & Backups

Save settings profiles, load shared RDR2 configs, and back up outfits, Lua scripts, and themes.

Configs & Backups

A config profile captures the menu settings you want to reuse. Use separate named profiles for different setups, and keep a copy of your current profile before trying someone else's.

Config folder and menu

Settings → GUI → Configs
Named profiles use the .config extension.

Save your current settings

  1. Set up the menu as you want it, then open Settings → GUI → Configs.
  2. Enter a New config name and select Save New.
  3. The saved profile becomes the active config. Use Open Folder to find its .config file.
  4. To update it later, use Quick Save Active. To overwrite another selected profile, use Save Selected and confirm the overwrite.

Choose a simple name such as MySetup. The menu adds the extension. default is reserved and is not a normal named profile.

Auto Save Features controls whether feature toggles and values are saved automatically. With it off, feature changes remain live for the session; a manual config save still captures them.

Install and load a shared profile

  1. Get a compatible Scooby RDR2 .config file and extract it if needed.
  2. Open the Configs screen and select Open Folder.
  3. Copy the file directly into C:\scooby\RDR2\configs. Keep its extension.
  4. Select Refresh, choose the profile in Config Library, then select Load Selected. You can also double-click its row.
  5. Check the active profile name and review the loaded feature settings before continuing.

A config changes menu settings. It does not copy the author's Lua scripts, outfit files, or image assets to your computer. Install those separately if the setup depends on them.

Back up your personal content

Close the game and Scooby, then copy the folders you want to preserve to your backup location:

  • C:\scooby\RDR2\configs — settings and named profiles.
  • C:\scooby\RDR2\outfits — player outfits and the Horse subfolder.
  • C:\scooby\RDR2\lua — scripts and their supporting configuration/data.
  • C:\scooby\RDR2\theme — saved appearance JSON files.
  • C:\scooby\RDR2\images — custom images and ListUI image themes.

Preserve filenames and folder structure. To restore a file, copy it back to the same location, then refresh the relevant library. Refreshing the Lua library stops running scripts, so start the scripts you need again afterward.

If a profile does not save or load

  • Not listed: check the .config extension, place the file directly in the configs folder, and refresh. The internal default.config is intentionally hidden from the named-profile list.
  • Invalid name: use 1–64 characters without Windows filename symbols such as \ / : * ?, and avoid the reserved name default.
  • Incompatible settings: restore the original file or ask for an export from a compatible Scooby RDR2 version. Renaming a GTA config does not convert it.
  • Images or scripts are missing: restore those files separately as well as the config.
