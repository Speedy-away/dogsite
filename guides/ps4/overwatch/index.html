Overwatch PS4 setup

Free to use. No Premium purchase or account login is required.

Install · Free · Controls · Help

Before you start

You need a GoldHEN-capable PS4, FTP access and the supported game below.

EU title ID: CUSA03974 · Game version: 04.40

Check your installed game's title ID and version before downloading. Get the Release ZIP from the Overwatch PS4 page.

1. Install the release ZIP

  1. Close Overwatch completely and extract the ZIP on your PC.
  2. Using FTP, copy the ZIP's GoldHEN and Scooby folders into /data/ on the PS4. The plugin should be here:
    /data/GoldHEN/plugins/ScoobyOverwatch.sprx
  3. Edit /data/GoldHEN/plugins.ini. Add or merge this entry, keeping your other games' entries:
    [CUSA03974]
/data/GoldHEN/plugins/ScoobyOverwatch.sprx
    Keep one active entry for this plugin; remove its older duplicate entry if needed.
  4. For the Scooby notification logo, copy the ZIP's user folder to the PS4 filesystem root /. The logo belongs under /user/data/Scooby/assets/notification/.
  5. In GoldHEN, open Plugin Settings → Enable Plugins. Start Overwatch.

When updating, keep your existing /data/Scooby/account.json and settings. Merge plugins.ini; do not replace all its entries.

2. Use Free

Start the game after installation. Overwatch is free-only; you do not need to enter a username or password.

The menu may create a blank /data/Scooby/account.json. You can leave it blank for Free.

3. Open the menu

Press R1 + Square to open or close Scooby.

D-pad: navigate · X: select · O: back.

If something does not work

  • Menu does not open: check the title ID, game version, plugin path and GoldHEN's Enable Plugins setting. Restart the game after changes.
  • Update required: close the game, install the latest Release ZIP from the product page and restart. Keep your account and settings.
  • Free disabled message: check the news at scoobymenu.cc.
