Rainbow Six Siege PS4 setup guide

Install the Scooby plugin and open the menu in-game.

This guide uses CUSA01800. The Rainbow Six Siege release page lists CUSA01788 for its download. Check your game title ID and confirm that your SPRX supports it before continuing.

Install and enable the plugin

  1. Close Rainbow Six Siege. Use FTP or Scooby Manager to copy ScoobyR6.sprx to the path below. 
    /data/GoldHEN/plugins/ScoobyR6.sprx
  2. Open /data/GoldHEN/plugins.ini and add this entry. 
    [CUSA01800]
/data/GoldHEN/plugins/ScoobyR6.sprx
  3. Open GoldHEN → Plugin Settings → Enable Plugins, then launch Rainbow Six Siege.

Open or close the menu

Press R1 + Square.
