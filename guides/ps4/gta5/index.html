GTA 5 PS4 setup guide

Install the Scooby plugin and open the menu in-game.

Install and enable the plugin

  1. Close GTA 5. Use FTP or Scooby Manager to copy ScoobyGTA.sprx to the path below. 
    /data/GoldHEN/plugins/ScoobyGTA.sprx
  2. Open /data/GoldHEN/plugins.ini and add the entry for your game region.

    Europe

    [CUSA00411]
/data/GoldHEN/plugins/ScoobyGTA.sprx

    USA

    [CUSA00419]
/data/GoldHEN/plugins/ScoobyGTA.sprx
  3. Open GoldHEN → Plugin Settings → Enable Plugins, then launch GTA 5.

Open or close the menu

Press R1 + Square.
