Red Dead Redemption 2 PS4 setup

Start with Free, or sign in to use your RDR2 Premium subscription.

Install · Free · Premium setup · Controls · Help

Before you start

You need a GoldHEN-capable PS4, FTP access and the supported game below.

EU title ID: CUSA08519 · Game version: 01.32

Check your installed game's title ID and version before downloading. Get the Release ZIP from the Red Dead Redemption 2 PS4 page.

1. Install the release ZIP

  1. Close Red Dead Redemption 2 completely and extract the ZIP on your PC.
  2. Using FTP, copy the ZIP's GoldHEN and Scooby folders into /data/ on the PS4. The plugin should be here:
    /data/GoldHEN/plugins/ScoobyRDR2.sprx
  3. Edit /data/GoldHEN/plugins.ini. Add or merge this entry, keeping your other games' entries:
    [CUSA08519]
/data/GoldHEN/plugins/ScoobyRDR2.sprx
    Keep one active entry for this plugin; remove its older duplicate entry if needed.
  4. For the Scooby notification logo, copy the ZIP's user folder to the PS4 filesystem root /. The logo belongs under /user/data/Scooby/assets/notification/.
  5. In GoldHEN, open Plugin Settings → Enable Plugins. Start Red Dead Redemption 2.

When updating, keep your existing /data/Scooby/account.json and settings. Merge plugins.ini; do not replace all its entries.

2. Use Free

For Free, leave the account fields blank and start the game. You do not need to buy a key.

The menu may create a blank /data/Scooby/account.json. You can leave it blank for Free.

Optional: set up RDR2 Premium

  1. Buy RDR2 Premium from the RDR2 PS4 product page, then sign in to the Scooby portal and redeem your key on your Scooby account.
  2. In the portal, use Download account.json under Redeem key. Enter your Scooby account username and password, then download the file. Use your account login, not the purchase key.
  3. Close RDR2. Upload the downloaded file with FTP to:
    /data/Scooby/account.json
  4. Restart RDR2 with an internet connection. Premium unlocks after the server verifies your account and active RDR2 subscription.

Prefer to edit it using FTP?

Start the menu once to create the blank file, close RDR2, then edit /data/Scooby/account.json. It should contain:

{
  "username": "",
  "password": ""
}

Fill the two values with your Scooby login, save the file as account.json (not account.json.txt), and restart the game. Use the portal download if your password contains quotes or backslashes.

Keep this file private. Do not share it in screenshots or support messages. No device ID setup is required in the current release.

3. Open the menu

Press R1 + Square to open or close Scooby.

D-pad: navigate · X: select · O: back.

If something does not work

  • Menu does not open: check the title ID, game version, plugin path and GoldHEN's Enable Plugins setting. Restart the game after changes.
  • Premium stays locked: check the account file path and your active RDR2 subscription in the portal. Restart RDR2 after editing the file.
  • Premium connection error: check the PS4 internet connection and date/time, then restart. If it still fails, send support the exact connection stage/error code. Never send your password or account.json.
  • Update required: close the game, install the latest Release ZIP from the product page and restart. Keep your account and settings.
  • Free disabled message: check the news at scoobymenu.cc.
