Guides/Megabonk/Languages and language packs

Languages and language packs

Select one of 23 Megabonk languages, download updates and preserve your custom translations.

Choose your language

Open Settings → Interface → Language in V1 or V2. The DLL includes all 23 language catalogs and installs them under C:/Scooby/Megabonk/lang. First launch does not need a separate language download.

Available languages: English, German, French, Russian, Spanish, Portuguese, Brazilian Portuguese, Italian, Polish, Turkish, Simplified Chinese, Traditional Chinese, Japanese, Korean, Thai, Hindi, Arabic, Hebrew, Dutch, Indonesian, Vietnamese, Serbian and Georgian.

Download updates

Click Download / update languages in Interface. The menu downloads and checks the collection before updating it, then refreshes the available languages. Existing catalogs stay usable if the server is unavailable.

Keep custom translations

Edit the strings values in your local locale JSON file. Keep the English keys, locale name, text placeholders and JSON structure intact. Updates preserve edited files. Rename or remove an edited file when you want to restore the distributed version.

Core Megabonk controls and the shared interface have translations. Other game messages and descriptions use English when a translation is unavailable. Item and unlock names follow the game’s own content catalog.

Language collection

The distribution folder is scooby/Megabonk/lang, containing index.json and one JSON file per locale. The index records file sizes, hashes and translation coverage.
