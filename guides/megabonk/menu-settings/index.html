Guides/Megabonk/Menu settings, configs and hotkeys

Menu settings, configs and hotkeys

Choose a UI edition, save Megabonk profiles, assign hotkeys and keep your preferred language.

Interface and language

Open Settings → Interface to choose V1 or V2, adjust menu and overlay scale, and select your language. Each edition remembers its presentation preferences. See language packs and updates.

Save and load configurations

Use Settings → Config to create, save, load or rename a profile and choose a default. Profiles preserve feature values and key bindings. The product data folder is C:/Scooby/Megabonk; keep a backup before replacing shared profiles.

Older configuration files remain supported through Misc → Progression → Legacy configurations. Importing an older file updates the corresponding menu values.

Set a hotkey

  1. Open Settings → Hotkeys, or the settings icon beside a feature.
  2. Choose its key button, then press a keyboard key or mouse button. Escape cancels capture; Delete clears the binding.
  3. Select the activation mode. Hold activates while pressed; Toggle changes state on each press; Always follows the feature’s enabled state.
  4. Save your profile to reuse the binding.

Numeric values do not automatically enable their feature or parent group. For example, enable Player modifiers before using a movement-speed override.
