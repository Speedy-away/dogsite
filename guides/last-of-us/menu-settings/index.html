The Last of Us Part I · Free and paid accounts

Menu settings

Interface

Open Settings → Interface to choose a language and adjust the separate UI scale and Overlay scale sliders from 50% to 200%.

Hotkeys

Open Settings → Hotkeys. Search for a feature, click its key button and press a key or mouse button. Escape cancels a binding and Delete clears it. Hold activates while pressed; Toggle switches state on each press; Always uses the feature checkbox.

Configs

Use Settings → Configs to create, save, load, rename or delete named profiles, set a default, or import and export via the clipboard. Configurations are stored in C:\scooby\Last Of Us\configs. The dashboard’s Open Folder link opens this product’s data folder.

Visuals and movement

Select NPC, Self or Items in ESP. Use the settings icon beside a feature for colors, outlines, gradients and supported positions. Box settings include corner boxes and fill. The control indicator explains active noclip and freecam controls.
