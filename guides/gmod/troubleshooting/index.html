Garry's Mod (GMOD) · Scooby Wiki

Troubleshooting

The menu does not open

Check that Steam's x86-64 branch is selected and fully updated. Launch Garry's Mod and load Scooby at the main menu, before joining a server or loading a map. Try the default Insert or F2 key, or your custom menu key if you changed it in Settings.

A feature is unavailable in a game mode

Gamemode tools depend on the active mode and server. Available information can differ between TTT, Murder, DarkRP, Prop Hunt, and GRust.

Problems after a game update

Game updates can affect compatibility. Check the GMOD product status and use Crashing Solutions or Universal Troubleshooting for further help.

Still need help?

Ask in the Scooby community ↗. Include the game, any error message, and the steps you have already tried.
