Judge Robe

Clothing and textures

Courtroom robes for male and female freemode characters.

By jimgordon20

FiveM server · Male and female freemode

Download from source ↗
Setup notes
  • Use the current Judge_Robe_fivem_f_and_m resource folder from the repository. Start it from server.cfg.
  • Check the add-on entries in your appearance menu on both freemode models. The author documents fixes in the current release.

FiveM server · Female freemode · Free Tebex checkout

Setup notes

Felis Missing Clothing Textures

Clothing and textures

Replacement textures for existing male and female clothing and props that show a checkerboard pattern.

By Felis Development

FiveM server · Texture replacements

Download from source ↗
Setup notes
  • Start fd_missing_textures before the clothing group, as shown in the README. The separate ydd and images folders are optional reference files.
  • Test the original clothing slots again after starting the resource. This pack replaces textures in those slots.
