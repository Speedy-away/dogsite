Qbox Framework

txAdmin recipe

Qbox’s full roleplay starter. It includes jobs, vehicles and inventory along with the framework’s other active resources.

By Qbox Project contributors

txAdmin · MariaDB 10.9+

fivem scooby server dumps txadmin

Download from source ↗
Setup notes
  • Install a current FXServer build and MariaDB 10.9 or newer. Qbox does not support MySQL or XAMPP.
  • Choose Qbox Framework in Popular Recipes and provide your database connection and Cfx.re server key.
