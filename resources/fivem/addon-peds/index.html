Popcorn RP Pets

Character and animal models

A free collection of animal models including a Chow Chow, a Dobermann, K9 dogs, an armadillo and a robot dog.

By Popcorn RP and credited contributors

FiveM server · Free · Animal models

Download from source ↗
Setup notes
  • Keep fxmanifest.lua, data and stream together in a resource folder named popcornrp-pets and add ensure popcornrp-pets to server.cfg.
  • Read the model name from the matching peds.meta entry. Pet interactions require a separate compatible resource such as keep-companion-ox.

Pablo ‘Fat Cop’ Taco

Character and animal models

A free human character model with casual outfits and police uniform variants for LSPD, BCSO and SAHP.

By TehHitman

FiveM server · Free · Human character

Download from source ↗
Setup notes
  • Open cfx-pablo-hitman.zip on the author’s repository and use the enclosed FiveM resource folder.
  • Start the resource by its folder name. Use the supplied model name in your server’s ped selector and test the outfit variants.

Anubis

Character and animal models

A fantasy character model with multiple eye and body variants and levels of detail for different viewing distances.

By SSERAFIM MODS

FiveM server · Paid Tebex release · Asset Escrow

Download from source ↗
Setup notes
  • Place the supplied sera_anubis folder in your server’s resources folder and add ensure sera_anubis to server.cfg.
  • Use sera_anubis as the model name in your server’s ped selector.
