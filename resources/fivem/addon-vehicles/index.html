ONX Declasse Granger Revamp + Alamo

Addon vehicles

Two civilian SUVs based on the Granger platform. The Alamo is the shorter variant.

By ONX, L’Kid and Tidemo

FiveM server · Free ONX store package

Download from source ↗
Setup notes
  • Claim the free package on the ONX store. Follow the creator’s instructions for putting the vehicle resources under [onx_vehicles] and starting that group in server.cfg.
  • Test the vehicles through your server’s vehicle spawner. The standalone download does not include the separate ONX traffic pack.

Grodd Customs Vehicle Pack

Addon vehicles

Seventeen civilian add-ons, including modified sedans, wagons, muscle cars and SUVs. The release lists the tuning options and spawn names for each.

By Grodd Customs

FiveM server · groddcustoms resource

Download from source ↗
Setup notes
  • Use the FiveM resource folder and add ensure groddcustoms to server.cfg.
  • Use the release’s model names when configuring your spawner or dealership. For a first test, the author lists senhart and oracle_gts.

Driving School Blista

Addon vehicles

A Blista with a driving school livery for lessons and roleplay events.

By Nukepug Designs

FiveM server · Model npdsblista

Download from source ↗
Setup notes
  • Install the npdsblista folder from the repository and add ensure npdsblista to server.cfg.
  • Use npdsblista as the model name in your authorized vehicle spawner or driving school resource.
