Legion Square +

Addon maps

A standalone YMAP redesign of Legion Square with new landscaping and props.

By zinpod (0breezy0)

FiveM server · Standalone YMAP

Download from source ↗
Setup notes
  • Put the breezy_legionplus folder under the server’s resources directory and add ensure breezy_legionplus to server.cfg.
  • Test it with other Legion Square maps disabled first so you can spot overlapping props or collision.

Coin’s Sandy Shores Project

Addon maps

A Sandy Shores YMAP with new props, memorials and changes to roadside scenery.

By Coin6969

FiveM server · CoinsSandyProject resource

Download from source ↗
Setup notes
  • Install the CoinsSandyProject folder that contains fxmanifest.lua and start that resource from server.cfg.
  • The author built this on the earlier CoinsTrees map. Compare it on its own before combining it with other Sandy Shores edits.

Omozan

Addon maps

A custom map from AndreIakko’s free MLO collection. The repository also contains vehicle and outfit resources in separate folders.

By AndreIakko

FiveM server · iak_omozan_map resource

Download from source ↗
Setup notes
  • For the map, install iak_omozan_map with its manifest and stream directory together. Start the resource on a test server.

bob74_ipl

Addon maps

A map utility for loading and customizing existing GTA V interiors and fixing missing map elements.

By Bob74 and contributors

FiveM server · Check for an existing copy

Download from source ↗
Setup notes
  • Check whether your framework already includes bob74_ipl. Use the release archive named bob74_ipl.zip and start the resource from server.cfg.
  • Use the upstream changelog to confirm your build and edition. The project documents separate streaming assets for Enhanced.
