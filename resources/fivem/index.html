ONX Declasse Granger Revamp + Alamo

Addon vehicles

Two civilian SUVs based on the Granger platform. The Alamo is the shorter variant.

By ONX, L’Kid and Tidemo

FiveM server · Free ONX store package

Download from source ↗
Setup notes
  • Claim the free package on the ONX store. Follow the creator’s instructions for putting the vehicle resources under [onx_vehicles] and starting that group in server.cfg.
  • Test the vehicles through your server’s vehicle spawner. The standalone download does not include the separate ONX traffic pack.

Popcorn RP Pets

Character and animal models

A free collection of animal models including a Chow Chow, a Dobermann, K9 dogs, an armadillo and a robot dog.

By Popcorn RP and credited contributors

FiveM server · Free · Animal models

Download from source ↗
Setup notes
  • Keep fxmanifest.lua, data and stream together in a resource folder named popcornrp-pets and add ensure popcornrp-pets to server.cfg.
  • Read the model name from the matching peds.meta entry. Pet interactions require a separate compatible resource such as keep-companion-ox.

RPEmotes Reborn

Animations and emotes

A standalone emote menu with built-in animations, shared emotes, props and support for custom animation lists.

By alberttheprince and contributors

FiveM server · OneSync Infinity

Download from source ↗
Setup notes
  • Extract the release into a resource named rpemotes-reborn and add ensure rpemotes-reborn to server.cfg.
  • The maintainers require OneSync Infinity for synchronization and recommend the latest supported game build. Use oxmysql if you enable SQL features.
