RPEmotes Reborn

Animations and emotes

A standalone emote menu with built-in animations, shared emotes, props and support for custom animation lists.

By alberttheprince and contributors

FiveM server · OneSync Infinity

Download from source ↗
Setup notes
  • Extract the release into a resource named rpemotes-reborn and add ensure rpemotes-reborn to server.cfg.
  • The maintainers require OneSync Infinity for synchronization and recommend the latest supported game build. Use oxmysql if you enable SQL features.

Hands in Pockets

Animations and emotes

A custom idle animation for roleplay scenes. The release supplies the dictionary and clip names.

By BzZzi

FiveM server · YCD animation · Emote integration

Download from source ↗
Setup notes
  • Use the archive attached to the author’s post and put the YCD in a resource’s stream folder.
  • Register dictionary bzzz@animations@hands and clip bz_hands in your emote resource. The author gives a DPEmotes example.
