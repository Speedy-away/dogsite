GTA 5 · STAND

Stand vehicle presets

  1. Choose an original Stand-compatible vehicle export.
  2. Open Vehicle → Garage → Open Folder and copy the preset there.
  3. Return to Garage, find the saved entry and select it. Install required addon models separately.

To import supported Stand data in Scooby or Nenyoo, select that menu above and follow its vehicle guide.

GTA 5 · STAND

Stand outfit presets

  1. Choose an outfit for the required character model.
  2. Open Self → Appearance → Outfit → Wardrobe → Open Folder and copy the compatible Stand preset there.
  3. Select it in Wardrobe to apply the outfit.

GTA 5 · STAND

Stand themes and headers

  1. Download the original Stand theme package and preserve its profile, theme and header folders.
  2. Use Stand → Open Stand Folder to locate the active installation, then follow the package’s readme for its original destinations.
  3. If a theme includes a profile, open Stand → Profiles → Open Folder, install that profile and load it through Profiles.

The author’s optional ThemeRepo manager uses ThemeRepo.pluto in %APPDATA%\Stand\Lua Scripts. Back up existing artwork before using it: its documented downloads replace the Theme and Custom Headers folders.

A Scooby ListUI style called Stand is installed through Scooby’s appearance controls. It is a separate package format.

ThemeRepo author instructions →

GTA 5 · STAND

Stand profiles

Back up your current settings. Use Stand → Profiles → Open Folder, copy the matching profile and load it through Profiles. Profiles store command settings; install referenced scripts and artwork separately.

GTA 5 · STAND

Stand Lua and Pluto scripts

  1. Check the required Stand version and API. A Download pending listing is a source reference until its package is available.
  2. Use Stand → Lua Scripts → Open Folder, or open %APPDATA%\Stand\Lua Scripts.
  3. Copy the available package’s original Lua or Pluto entry file and dependencies. Keep its resources and store directories where the author specifies.
  4. Select the installed script in Stand’s Lua Scripts library.

Stand’s Lua / Pluto API is separate from Scooby, Nenyoo, Cherax and X-Force scripting APIs.

GTA 5 · STAND

Stand language selection

Select a supplied language under Stand → Settings → Language. For a script translation, follow that script’s language instructions and preserve its language files. Use a manual menu-translation package only when its author documents the matching Stand build and installation method.

GTA 5 · STAND

Stand addon packs

  1. Open the pack’s source page for its download and setup instructions.
  2. Back up your Stand folder before copying profiles, scripts or artwork. Keep the pack’s folder structure and follow the author’s instructions for each component.

GTA 5 · APPEARANCE FILES

Menu wallpapers

  1. Choose artwork for the selected menu and its background or header slot.
  2. Open ’s matching appearance controls. Use the slot’s image browser or folder control when provided.
  3. Keep theme-bundled artwork at the relative paths specified by its author, then select or reload the corresponding image.

Wallpaper folders vary by menu, theme and version. Use the active appearance control or the package readme for its destination.

GTA 5 · RESOURCE PACKAGES

Other files and required loaders

  1. Check the resource’s target game edition, required host and original installation instructions.
  2. Use the author’s documented loader for game assets, ASI plugins or .NET scripts. For a menu import, use the corresponding library’s folder control when provided.
  3. Keep the complete package and dependencies together and follow its activation instructions.

The selected menu identifies the destination collection. Each package still requires its stated loader and supported file format.
