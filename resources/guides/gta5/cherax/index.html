GTA 5 · CHERAX

Cherax vehicle and outfit presets

  1. For the built-in libraries, choose a Cherax .json preset for your version and the correct vehicle or character model.
  2. Open the matching saved-vehicle or outfit library. Use its Open Folder or Import control when provided; otherwise follow the resource’s original readme.
  3. Keep the file’s original format and dependencies. Refresh or reopen the library and select the imported preset.

Menyoo .xml, .ini and other menus’ JSON schemas need a compatible Lua loader. Check the listing for the matching importer.

Supported Cherax vehicle and outfit data can also use Scooby’s or Nenyoo’s importers. Select the destination menu above for its verified folders. This data support does not extend to Cherax Lua APIs, themes or languages.

GTA 5 · CHERAX

Cherax Lua scripts

  1. Check the required Cherax build and API. Its public API documentation specifies Lua 5.4; individual scripts can require a particular API generation.
  2. For an available matching package, open Cherax’s script folder control or use %APPDATA%\Cherax\Lua, the directory documented by Cherax.
  3. Copy the script with its complete dependency folders, then load it using Cherax’s script library.

If a script offers multiple versions, choose the release that matches your Cherax build and download that version.

GTA 5 · CHERAX

Cherax themes, configs and languages

  1. Choose a file explicitly packaged for the installed Cherax build and the selected resource type.
  2. Open the corresponding appearance, config or language library. Use its import or folder control when available; otherwise use the destination in the author’s readme.
  3. Back up your current files, preserve the package structure and load it through the matching Cherax control.

For themes, select ClickGUI or ListUI in Cherax and import the files made for that interface. Dual-interface packs include separate settings for each interface.

GTA 5 · CHERAX

Vehicle DLC packs

  1. For a compatible ModVerse RPF7 pack, follow the ModVerse DLC setup for Cherax.
  2. For an author-hosted vehicle, choose the archive for your game edition and follow the author’s Story Mode installation instructions.
  3. Keep the model, textures and metadata together. Use the vehicle’s supplied model name after loading the DLC.

GTA 5 · APPEARANCE FILES

Menu wallpapers

  1. Choose artwork for the selected menu and its background or header slot.
  2. Open ’s matching appearance controls. Use the slot’s image browser or folder control when provided.
  3. Keep theme-bundled artwork at the relative paths specified by its author, then select or reload the corresponding image.

Wallpaper folders vary by menu, theme and version. Use the active appearance control or the package readme for its destination.

GTA 5 · PLACEMENT MAPS

Map presets that require Lua

Open the map through a Lua loader that supports its exact format. Use Constructor for supported Stand map files, or the matching Cherax importer listed on the resource, such as BiggerScript. Install any model dependencies separately.

GTA 5 · RESOURCE PACKAGES

Other files and required loaders

  1. Check the resource’s target game edition, required host and original installation instructions.
  2. Use the author’s documented loader for game assets, ASI plugins or .NET scripts. For a menu import, use the corresponding library’s folder control when provided.
  3. Keep the complete package and dependencies together and follow its activation instructions.

The selected menu identifies the destination collection. Each package still requires its stated loader and supported file format.
