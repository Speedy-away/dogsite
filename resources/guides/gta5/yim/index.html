GTA 5 Legacy · Yim v1

Install Lua scripts in Yim v1 (Legacy)

  1. Download a package from Yim v1 Lua scripts, extract the ZIP, and check the included instructions for any dependencies.
  2. Open Settings → Lua Scripts → Open Lua Scripts Folder in YimMenu. You can also press Win + R and enter %AppData%\YimMenu\scripts.
  3. Copy the entry .lua file and its supporting files into that folder. Keep their relative paths. If the package tells you to copy a whole folder, such as SSV2, copy it intact.
  4. In Lua Scripts, select Reload All and look for the script. Check the package instructions for the tab or hotkey that opens it.

If a script fails to load, check that you extracted the ZIP, kept its dependencies together and downloaded the version for your YimMenu and game build. Libraries and Lua Language Server files have their own setup instructions.

GTA 5 Legacy · Yim v1

Import JSON and XML vehicles in Yim v1

  1. Download a vehicle pack and extract it. Pick the presets you want to add.
  2. Copy .json files to %AppData%\YimMenu\saved_json_vehicles or .xml files to %AppData%\YimMenu\xml_vehicles.
  3. Open the matching saved or XML vehicle list in YimMenu. Refresh the list and select a preset.

Some presets reference additional models or attachments. If a vehicle loads with parts missing, check that those assets are available in your game build.

GTA 5 Legacy · Yim v1

Import XML maps in Yim v1

  1. Extract the XML map pack and choose a map.
  2. Copy its .xml file to %AppData%\YimMenu\xml_maps.
  3. Open YimMenu’s XML map list, refresh it, and select the map. Load any models it requires before importing it.

GTA 5 Legacy · Yim v1

Import JSON outfits in Yim v1

  1. Extract the outfit pack and copy the chosen .json files to %AppData%\YimMenu\saved_outfits.
  2. Open YimMenu’s saved outfits, refresh the list, and select the preset for your character model.
