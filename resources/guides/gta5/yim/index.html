Install YimMenu Lua scripts

Extract the ZIP and check the included instructions for the required YimMenu and GTA 5 versions. Copy the script and its supporting folders into the scripts folder for your YimMenu build. Keep the original folder structure, then reload scripts from the Lua menu.

Lua libraries and editor tooling have their own setup instructions in the package.
