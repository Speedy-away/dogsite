GTA 5

ClickUI and ListUI themes

  1. Choose a Scooby appearance JSON or theme bundle. Extract it and copy the JSON, or the complete bundle with its images, into C:\scooby\GTA5\themes.
  2. Open Settings → Appearance → Themes and select Refresh Library.
  3. Select the theme, choose Both, ClickUI or ListUI under Save / Load Scope, then select Load Selected Theme.

Keep the JSON at the top of its bundle folder. Standalone ClickUI appearance presets can use themes\ClickUI; use the package readme and the menu’s folder control for that format. A theme only supplies interfaces included in its export. For a style-specific Stand profile or X-Force UI preset, use the matching native ListUI style controls and its package instructions.

Scooby themes can borrow another menu’s appearance while using Scooby’s own format. Original Cherax ClickGUI themes belong in Cherax’s theme library. For Scooby ClickUI, choose a version made for Scooby.

GTA 5 / RED DEAD REDEMPTION 2

ListUI style image packs

  1. Choose a pack made for your menu and its active ListUI style.
  2. For builds using native style profiles, use C:\scooby\GTA5\Themes\ListUI or C:\scooby\RDR2\Themes\ListUI.
  3. Keep the pack in the exact style folder supplied by the author, such as 2TAKE1, IMPULSE, Stand, Silkroad v3-v4, Silkroad Simple, Ozark v34 or X-Force v6.
  4. Use the ListUI appearance controls to choose the style and reload its images. Keep all backgrounds, headers and selection images together.

Older RDR2 builds use the separate images\ListUI workflow below. Use your menu’s Open Folder control and the package readme to select the correct format. Navigation layout samples are separate from image themes.
