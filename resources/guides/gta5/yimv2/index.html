Install Lua scripts in Yim v2 (Enhanced)

  1. Download a package from Yim v2 Lua scripts and extract the ZIP.
  2. In YimMenu v2, open Settings → Lua Scripts → Open Lua Scripts Folder. You can also open %AppData%\YimMenuV2\scripts directly.
  3. Copy the files as directed by the package. For Samurai’s Scripts Enhanced, copy samurais_v2.lua and the includes folder from SSV2-enhanced into scripts. Keep the folder contents together.
  4. Open Lua Scripts. If the new script appears under Disabled, select it to load it. If it is already enabled and you replaced its files, select it and choose Reload.

YimMenu v2 uses its own Lua API. Match the script’s stated YimMenu v2 and GTA 5 Enhanced build requirements when troubleshooting a load error.
