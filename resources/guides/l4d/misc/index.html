LEFT 4 DEAD 1 & 2

Install game add-ons

  1. Check the listing’s game and required items. Follow its author’s instructions for any special installation steps.
  2. For an L4D2 Workshop item, select Subscribe on Steam. Start L4D2 and let it finish downloading the add-ons.
  3. For a manual .vpk, close the game and extract the VPK if it arrived in an archive. In Steam, use Manage → Browse local files on the matching game. Copy the VPK into left4dead\addons for L4D1 or left4dead2\addons for L4D2.
  4. Launch the game and check its Add-ons menu. If two replacements change the same model, texture, or sound, enable one at a time.

Other resource files
