GTA 5

ASI mods and trainers

  1. Select Download on the Scooby resource. Check its Edition and Requirements, then read the package’s included instructions.
  2. Install the ASI loader and Script Hook V version specified in those instructions. Legacy and Enhanced releases can have different requirements.
  3. Extract the complete mod package. Place its ASI plugin, configuration and supporting folders where the included readme instructs; many plugins use the folder containing the game executable.
  4. Start the game and use the activation key listed in the mod’s instructions. Keep the original package so you can identify its installed files later.

Menyoo, Rampage and Simple Trainer use their own documented exports and supporting folders. Preserve their original files when installing a downloaded package.

Download ASI mods on Scooby →

GTA 5

.NET mods

  1. Select Download on Scooby. Check the resource’s required GTA edition, Script Hook V, .NET script host and runtime versions.
  2. Install the host and its documented dependencies before adding the mod. Follow the package’s edition-specific instructions.
  3. Extract the mod with all of its supporting files. Use the scripts folder or other destination specified in the included readme.
  4. Keep DLLs, configuration, images and data folders together as supplied. Follow the mod’s activation and troubleshooting instructions.

A .NET game mod runs through its documented script host. Keep its host and runtime requirements with the downloaded package.

GTA 5

Menyoo / XML vehicles and map mods

  1. Check whether the download is a saved vehicle, an object-placement map or a model package. Keep XML, INI and JSON exports in their original format.
  2. For a supported vehicle XML, use Scooby’s Vehicle → Saved Vehicles library and its folder control, then refresh and select the file.
  3. For a placement map, use a compatible map loader or the Menyoo / Simple Trainer workflow named by its author. Use that loader’s folder control or the package’s documented map directory.
  4. Install any required custom vehicle, ped or map assets first. A placement preset can only reference models available to its loader.

A trainer-specific map and a streamed map asset are different formats. Changing a filename extension does not convert between them.

GTA 5

Outfits

  1. Download a compatible outfit and preserve its extension. Native saves use JSON; supported XML outfits also load.
  2. Open Self → Outfit Editor → Saved Outfits → Open Folder, or open C:\scooby\GTA5\outfits.
  3. Copy the outfit there, select Refresh, and select the file to apply it.
  4. Use the character model and game edition the outfit was made for.

Current builds also browse supported Stand, Cherax, INI and Menyoo exports through the ordinary outfit library. Use the same outfits folder, preserve the original structure and choose the supported importer. Older other-menu folders are migrated by current builds. An extension alone does not guarantee compatibility.

GTA 5

Vehicles and modded builds

  1. Download the original preset. Supported structures include JSON, XML and INI; the file’s contents must match a supported importer.
  2. Open Vehicle → Saved Vehicles → Open Folder, or open C:\scooby\GTA5\vehicles.
  3. Copy the preset there, open Browse, select Refresh, and select the vehicle.
  4. Current builds also browse compatible other-menu exports in this same library. Preserve their original format and folder structure.

A saved build references existing vehicle models and attachments. Install any required addon models separately. Renaming an extension does not convert the preset.

GTA 5

Addon vehicles, peds and textures

  1. Download the resource on Scooby and check its Edition, Requirements and included readme. RPF, YFT, YDD and YTD files are game assets.
  2. For the split Scooby addon collection, download all seven archive parts into the same folder. Keep their names unchanged and extract the .zip.001 with an archive tool that supports split ZIPs.
  3. Choose a vehicle pack under addons/vehicles/Legacy or Enhanced. In a compatible Scooby build, import your chosen content through Addons/Replacements. For a loose ped, import its complete ped folder.
  4. Follow the package readme and keep dependencies together. Supported Legacy packs can use Settings → Converter for Enhanced; moving a folder between editions does not convert it.
  5. After the assets are installed, use the supplied spawn name or load the compatible vehicle/outfit preset.

For texture packages, check the exact target model and required loader. Keep original downloads and avoid replacing files while a pack is mounted.

RED DEAD REDEMPTION 2

Addon peds

  1. Download the complete ped ZIP on Scooby and read its Requirements and included COMMUNITY-INSTALL.txt.
  2. Copy the ZIP into C:\scooby\RDR2\Addon Archives.
  3. Open Addons/Replacements → Archives → Refresh Archives. Select the pack root and choose Import to Library.
  4. Use Refresh Library, then Validate Direct Pack before choosing a compatible load or staging action.

Direct Pack loading is experimental in the native menu. LML staging requires Lenny’s Mod Loader and applies on the next game launch. Archive validation and in-game model registration are separate steps.

GTA 5

LSC paintjobs

  1. Download the paintjob’s native Scooby JSON and keep any category folders supplied with it.
  2. Get inside the vehicle you want to paint. Open Vehicle Editor → Save/Load Paint Jobs → Open Folder.
  3. Copy the JSON into C:\scooby\GTA5\LSC\PaintJobs, preserving its category folder when present.
  4. In Save/Load Paint Jobs, choose the matching Folder and Saved Paint Job.
  5. Select Load Paint Job to apply it to your current vehicle.

The paintjob library accepts native JSON files in the scooby.paintjob format. The resource collection includes 2,299 native paintjobs. Vehicle livery texture packages have their own installation category.

GTA 5

ClickUI and ListUI themes

  1. Choose a Scooby appearance JSON or theme bundle. Extract it and copy the JSON, or the complete bundle with its images, into C:\scooby\GTA5\themes.
  2. Open Settings → Appearance → Themes and select Refresh Library.
  3. Select the theme, choose Both, ClickUI or ListUI under Save / Load Scope, then select Load Selected Theme.

Keep the JSON at the top of its bundle folder. Standalone ClickUI appearance presets can use themes\ClickUI; use the package readme and the menu’s folder control for that format. A theme only supplies interfaces included in its export. For a style-specific Stand profile or X-Force UI preset, use the matching native ListUI style controls and its package instructions. Original Cherax or Stand appearance files require an explicitly supported adapter or port.

GTA 5

Config profiles

  1. Open the menu’s config library and use its folder control to find the active profile directory.
  2. Back up your current settings, then copy a compatible Scooby exported profile into that directory.
  3. Refresh the config list, select the profile and load it. Review the loaded settings.

Edition-specific profiles use C:\scooby\GTA5\configs\Enhanced or Legacy. With shared configs enabled, the directory is C:\scooby\GTA5\configs\Shared. Use the active menu folder rather than guessing the edition.

COUNTER-STRIKE 2

Players, weapons, knives and equipment

  1. For a package in the in-game repo, open Custom → Repo, search or filter by category, preview it and choose Download and install.
  2. For a downloaded archive, extract the complete resource trees. In Custom → Library, open the category’s gear menu and choose Import folder or Import weapon folder.

REDM

RSG object streaming files

  1. Download the complete file set supplied with the RSG prop listing, including its model, texture and archetype files.
  2. Place the original YDR, YTD and YTYP files together in a compatible RedM server resource’s stream folder.
  3. Preserve the source resource’s manifest and register stream/prop_weed_ytyp.ytyp using its DLC_ITYP_REQUEST data-file declaration.
  4. Have the server owner start the resource and use the supplied model names after it loads.

These are RedM server assets. Native single-player Scooby RDR2 import compatibility has not been established.

Client preset folders do not install server resources. Access to a server does not grant permission to change its resources.

Config profiles

  1. Match the game, file format and required Scooby version.
  2. Use the game’s config library and its Open Folder or Import control.
  3. Back up your current settings, copy the complete profile, refresh the library and load the config.

SCOOBY FILES

Lua scripts

  1. Check the resource’s download state, game, required Scooby version, host API and Lua runtime.
  2. A listing marked Download pending has no installable download yet. Its source listing and changelog provide context; wait for a matching package before installing.
  3. For an available script, review the package and use the script library’s folder control. Preserve supporting modules and filenames.
  4. Refresh the script library and run the script from that library.

GTA 5 scripts use C:\scooby\GTA5\lua.

RDR2 scripts use C:\scooby\RDR2\lua. The RDR2 and GTA 5 APIs are separate.

Use your game’s script library folder control and its supported scripting API.

Use a native Scooby script or a compatibility target supplied by your current build. Cherax and Stand scripts require their matching compatibility layer and supported API calls. Check the resource’s requirements; a listed source script may use features outside that layer.

  1. Download the original image and check whether it is intended for ClickUI, a ListUI style or another appearance slot.

GTA 5 · NENYOO

Nenyoo saved vehicles

  1. Download a preset supported by Nenyoo’s vehicle importer. Keep its original JSON, XML, INI or TXT structure.
  2. Open Saved Vehicles → Open Folder, or open %LOCALAPPDATA%\Nenyoo\Plus\Vehicles.

GTA 5 · NENYOO

  2. Copy the original preset into %LOCALAPPDATA%\Nenyoo\Plus\Outfits.
  3. Open Outfits → Saved Outfits and select the file to apply it.
  4. Keep any required model assets and attachments with their original installation instructions.

The current library scans XML, JSON, INI, CFG and TXT files; the contents must match a supported outfit format. Supported other-menu data stays in its original format.

GTA 5 · NENYOO

GTA 5 · NENYOO

  4. Allow the library to process the package, review the reported result, then open its pack entry and use its supported actions.

Models become available through the matching vehicle, model or object browser after loading. Follow the original readme for packages that require another loader.

GTA 5 · NENYOO

  2. Place the folder in %LOCALAPPDATA%\Nenyoo\Plus\Themes. Keep the supplied relative paths intact.
  3. Open Settings → Choose Theme and select the installed theme. Use Reload Lua Theme after editing its files.

Nenyoo themes execute through its theme API. A style named Stand or X-Force still requires the Nenyoo version of that theme; original host presets and Scooby appearance JSON use their own loaders.

GTA 5 · NENYOO

GTA 5 · NENYOO

Nenyoo user scripts

  1. Check the listing’s download state and required Nenyoo API or explicitly supported dialect. Download pending means an installable package is not available yet.
  2. For an available compatible package, open Scripts → Open Scripts Folder. This opens %LOCALAPPDATA%\Nenyoo\Plus\Scripts\User.
  3. Preserve the package’s entry script, modules and relative folders. Select Refresh Script List, choose the script and use its load action.

Nenyoo builds can provide API compatibility layers, including the shipped Stand layer. Match the script’s required dialect and supported calls to your installed build; a source listing alone does not establish full runtime compatibility. Themes belong in Themes, and built-in API files belong to the menu installation.

Nenyoo loads its translation assets through its runtime package. lang.cfg stores the selected language; it is not a translation catalog. Scooby Languages files use a different host format.

GTA 5 · X-FORCE

X-Force scripts

  1. Check the original author’s supported X-Force build, script API and dependencies.
  2. For an available package, use X-Force’s script-library folder or import control when provided. Follow the package readme for its entry script and supporting files.
  3. Load the script through that host’s script library.

A Download pending listing is not an installable script yet. Other menus’ vehicle or outfit import support does not establish X-Force Lua API compatibility.

GTA 5 · X-FORCE

X-Force config and language files

  1. Use a package documented for the installed X-Force version.
  2. Back up the existing file and use the matching config or language import / folder control when provided.
  3. Keep the original names and dependencies and follow the author’s readme for loading it.

Use an explicit destination from the installed host or the package documentation; these formats do not share Scooby’s config and Languages folders.

GTA 5 · ADDON ASSETS

DLC and addon requirements

  1. Read the addon’s original installation instructions and check the GTA edition and required loader.
  2. Install the full asset package through that documented loader. A downloaded model pack can require additional tools even when a preset is listed for .
  3. Preserve metadata, textures, model and animation dependencies. Use the package’s supplied model names after loading.

A saved vehicle or outfit preset does not install its referenced DLC assets. Only use a native addon importer when the installed menu explicitly supports that package format.

GTA 5 · APPEARANCE FILES

Menu wallpapers

  1. Choose artwork for the selected menu and its background or header slot.
  2. Open ’s matching appearance controls. Use the slot’s image browser or folder control when provided.
  3. Keep theme-bundled artwork at the relative paths specified by its author, then select or reload the corresponding image.

Wallpaper folders vary by menu, theme and version. Use the active appearance control or the package readme for its destination.

GTA 5 · RESOURCE PACKAGES

Other files and required loaders

  1. Check the resource’s target game edition, required host and original installation instructions.
  2. Use the author’s documented loader for game assets, ASI plugins or .NET scripts. For a menu import, use the corresponding library’s folder control when provided.
  3. Keep the complete package and dependencies together and follow its activation instructions.

The selected menu identifies the destination collection. Each package still requires its stated loader and supported file format.

GTA 5 · YIM

Yim guides are coming later

Yim support is deferred. Verified resource formats and installation instructions will be added with its collection.

SCOOBY FILES

Other resource files

  1. Check the resource’s game, required version and included readme.
  2. Use the relevant Open Folder or Import control and preserve the full package’s filenames and supporting folders.
  3. Follow the author’s instructions for that resource type.
