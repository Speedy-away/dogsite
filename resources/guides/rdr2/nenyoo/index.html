Bundled assets and loader translations

Match the resource to your Nenyoo build and keep its source filename and folder structure. Loader translations are shared between games. Fonts, textures and emote audio are listed under the game that supplies them.

RED DEAD REDEMPTION 2 · NENYOO

RDR2 translations

Choose the language supplied with your Nenyoo RDR2 build. Match any replacement JSON to the RDR2 translation folder and keep the original filename. Use the Loader translations category for the launcher.

RED DEAD REDEMPTION 2 · NENYOO

Built-in RDR2 Lua modules

Use the Nenyoo RDR2 build that supplies these HUD and camera features. The catalog links to their original Lua source. The runtime loads the modules from its own feature folders.
