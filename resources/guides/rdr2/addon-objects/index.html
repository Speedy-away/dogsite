RED DEAD REDEMPTION 2

Addon objects, animations and maps

  1. Download the RDR2 resource on Scooby and read its Requirements and included installation instructions.
  2. Keep the complete asset package and all supporting folders together.
  3. Install any required loader or dependencies and follow the included readme for the package’s destination.
  4. Use the supplied model names or compatible presets after installation.

Choose a package made for RDR2 and the loader specified in its instructions.
