RED DEAD REDEMPTION 2

Addon peds

  1. Download the complete ped ZIP on Scooby and read its Requirements and included COMMUNITY-INSTALL.txt.
  2. Copy the ZIP into C:\scooby\RDR2\Addon Archives.
  3. Open Addons/Replacements → Archives → Refresh Archives. Select the pack root and choose Import to Library.
  4. Use Refresh Library, then Validate Direct Pack before choosing a compatible load or staging action.
  5. Keep install.xml, ped metadata and all streaming dependencies together. Use the package’s model names after registration and loading.

Direct Pack loading is experimental in the native menu. LML staging requires Lenny’s Mod Loader and applies on the next game launch. Archive validation and in-game model registration are separate steps.

RED DEAD REDEMPTION 2

Addon objects, animations and maps

  1. Download the RDR2 resource on Scooby and read its Requirements and included installation instructions.
  2. Keep the complete asset package and all supporting folders together.
  3. Install any required loader or dependencies and follow the included readme for the package’s destination.
  4. Use the supplied model names or compatible presets after installation.

Choose a package made for RDR2 and the loader specified in its instructions.

GTA 5 / RED DEAD REDEMPTION 2

ListUI style image packs

  1. Choose a pack made for your menu and its active ListUI style.
  2. For builds using native style profiles, use C:\scooby\GTA5\Themes\ListUI or C:\scooby\RDR2\Themes\ListUI.
  3. Keep the pack in the exact style folder supplied by the author, such as 2TAKE1, IMPULSE, Stand, Silkroad v3-v4, Silkroad Simple, Ozark v34 or X-Force v6.
  4. Use the ListUI appearance controls to choose the style and reload its images. Keep all backgrounds, headers and selection images together.

Older RDR2 builds use the separate images\ListUI workflow below. Use your menu’s Open Folder control and the package readme to select the correct format. Navigation layout samples are separate from image themes.

RED DEAD REDEMPTION 2

Player and horse outfits

  1. Copy a Scooby RDR2 outfit JSON directly into C:\scooby\RDR2\outfits. Horse outfits belong in its Horse subfolder.
  2. For a player outfit, open Self → Outfits → Outfits → Saved Outfits.
  3. Select Refresh, select the file, and choose Load Selected Outfit.

Check the intended character, model and Online gender. RDR2 outfit files are separate from GTA 5 and RedM exports. The outfit editor requires a license that includes the feature.

RED DEAD REDEMPTION 2

Appearance and ListUI images

  1. Copy saved appearance JSON directly into C:\scooby\RDR2\theme. This folder is singular.
  2. Open Settings → Appearance → Themes → Saved Themes, refresh, select the theme and choose Load.
  3. For a ListUI image theme, copy the whole image folder into C:\scooby\RDR2\images\ListUI.
  4. Open the ListUI Images controls, select Reload Images, choose the theme with Next Theme, and enable the desired slots.

Preserve slot filenames such as header, background and selector. Appearance JSON and image themes are separate; install both when supplied.

RED DEAD REDEMPTION 2

Config profiles

  1. Back up your current profile. Copy the compatible .config file directly into C:\scooby\RDR2\configs.
  2. Open Settings → GUI → Configs and select Refresh.
  3. Choose the file in Config Library and select Load Selected.

A config does not install its author’s scripts, themes or outfits. Install those separately.

SCOOBY FILES

Lua scripts

  1. Check the resource’s download state, game, required Scooby version, host API and Lua runtime.
  2. A listing marked Download pending has no installable download yet. Its source listing and changelog provide context; wait for a matching package before installing.
  3. For an available script, review the package and use the script library’s folder control. Preserve supporting modules and filenames.
  4. Refresh the script library and run the script from that library.

RDR2 scripts use C:\scooby\RDR2\lua. The RDR2 and GTA 5 APIs are separate.

Use a native Scooby script or a compatibility target supplied by your current build. Cherax and Stand scripts require their matching compatibility layer and supported API calls. Check the resource’s requirements; a listed source script may use features outside that layer.

SCOOBY FILES

Translations and languages

  1. Choose a translation catalog that matches your game and Scooby build.
  2. Use the language library’s Open Folder or Import control and copy the full package.
  3. Preserve filenames and supporting files, refresh the library and load the language.

RDR2 custom language overrides use C:\scooby\RDR2\Languages. Keep the menu-managed Downloaded cache separate from your custom overrides.

Translation catalogs and layouts must match the host build. Keep any existing custom language overrides.

SCOOBY FILES

Other resource files

  1. Check the resource’s game, required version and included readme.
  2. Use the relevant Open Folder or Import control and preserve the full package’s filenames and supporting folders.
  3. Follow the author’s instructions for that resource type.
