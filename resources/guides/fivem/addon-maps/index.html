FIVEM / REDM

Server resources and custom assets

  1. Download the resource on Scooby and check the intended runtime, requirements and dependencies. FiveM and RedM use separate resource packages.
  2. If the download is a server resource, give it to the server owner or install it using the included server instructions.
  3. Keep its resource manifest, stream folders and supporting files together. Follow the readme for server configuration and startup order.
  4. For a menu preset, use the menu’s import or Open Folder control instead.

Client preset folders do not install server resources. Access to a server does not grant permission to change its resources.

FIVEM

Install and test a FiveM map add-on

  1. Check the maintainer’s required server edition, game build and dependencies. A YMAP places map objects. A custom interior can also include models, textures, collision and YTYP definitions. Keep the author’s files together.
  2. On a test server, copy the folder with fxmanifest.lua into resources and add ensure followed by its folder name to server.cfg. If the archive wraps several resources, start the map folder named in the instructions.
  3. Connect and visit the area with other maps for that location disabled. Check entrances, floors and doors from both sides. Reconnect and check again so you can catch missing assets that only show up when a player first joins.
  4. Enable the other maps one at a time. If walls flicker, objects appear twice or collisions no longer match, stop the last resource you enabled and compare again. Keep a copy of the previous server.cfg so you can restore the working setup.
