FIVEM / REDM

Server resources and custom assets

  1. Download the resource on Scooby and check the intended runtime, requirements and dependencies. FiveM and RedM use separate resource packages.
  2. If the download is a server resource, give it to the server owner or install it using the included server instructions.
  3. Keep its resource manifest, stream folders and supporting files together. Follow the readme for server configuration and startup order.
  4. For a menu preset, use the menu’s import or Open Folder control instead.

Client preset folders do not install server resources. Access to a server does not grant permission to change its resources.

FIVEM

Install FiveM graphics packs and textures

  1. Open the listing’s author page and choose the FiveM release. Check whether it is a client graphics pack, a ReShade preset, or a server-streamed resource.
  2. For a client graphics pack, close FiveM, extract the archive, and follow the author’s installation path. For example, Hiromasa documents %LOCALAPPDATA%/FiveM/FiveM.app/plugins for its packs. Keep a backup of any files you replace.
  3. For a ReShade preset, install the required shaders and any named base mod, such as QuantV. Put the preset .ini in your ReShade presets folder and select it in the overlay.
  4. For a server-streamed package such as Oulsen’s satellite map, have the server operator keep the manifest and stream files together, add the resource to the server’s resources directory, and enable it in server.cfg.

Cfx.re documents that client graphics mods are unavailable in FiveM for GTA V Enhanced during early access. Check the game edition and the server’s client-mod policy before installing.

FIVEM

Compare graphics packs and check performance

  1. Start with stock graphics and take a baseline in a private test session. Keep the same location, camera angle, resolution and game settings for both passes.
  2. Check the same street in clear daylight, at dusk and at night. In daylight, look for detail in white walls, clouds and signs. At dusk, check for lost detail in shaded doorways. At night, check whether streetlights bloom over road markings or make the HUD hard to read.
  3. Walk the same route and pan past fences, foliage and signs. These fine details make shimmer, ghosting and oversharpening easier to spot. At a waterfront, check that the sunset reflection keeps detail around the brightest part.
  4. Repeat the route with one pack or preset changed. Compare frame times and visible stutter along with average FPS. A clip recorded on a different server or at a different time of day is useful for judging the look, but cannot establish a performance gain.

If the result looks wrong or FiveM crashes, close the game, roll back the last change and retest the stock setup before adding anything else.

FIVEM

Load and tune a ReShade preset

  1. On a compatible FiveM Legacy setup where the server allows ReShade, save the preset .ini in the presets folder named by its author. Keep your current preset as a separate file.
  2. Open the ReShade overlay and select the new file from the preset selector on the Home tab. If an effect fails to load, check the author’s shader list and the overlay log. In a preset, the Techniques line can help you identify missing .fx files.
  3. Compare effects on and off from the same camera angle. If shadows look flat or signs lose detail, try adjusting the color or contrast effect first. If pavement and brick edges look grainy while moving, turn down sharpening and check whether more than one sharpening effect is active.
  4. Save your changes to a copy. If the overlay never appears, check your game edition and the server’s policy before changing anything else.

FIVEM

Tell a preset from a full client pack

  • A ReShade preset is typically an .ini with a list of shader dependencies. Load it through your compatible ReShade installation and keep your previous preset so you can switch back.
  • A pack with a citizen folder can replace client files. Check the archive against the maintainer’s file list and game edition before changing anything. If the archive includes runtime DLLs or has no original release, skip it and choose a documented pack.
  • An archive labelled DLSS may bundle ReShade and third-party DLLs. Upscaling, frame generation and neural rendering have different hardware requirements. Check the original project’s compatibility notes for your exact GPU and edition before installing; a filename naming a GPU series is insufficient. Cfx.re says graphics mods are unavailable on FiveM Enhanced during early access.

Check the server’s client plugin policy first. To troubleshoot a compatible pack, start with the stock client, add one documented component at a time and back up the exact files you replace.

FIVEM

Set up a mixed FiveM pack one component at a time

  1. Open the archive outside FiveM and check its folder tree. A bundle can put a ReShade preset, audio replacements and a citizen folder under a single wrapper directory. Open any nested archive separately and match each component to its original maintainer’s instructions and supported edition.
  2. Close FiveM. Confirm the path to your active installation before changing files. Cfx.re’s installer normally uses %LOCALAPPDATA%\FiveM and can also install into a folder you choose. Write down the files each component adds or replaces and keep copies of the originals outside the game folders.
  3. Try the component you want first. Launch FiveM and test it before adding the next one. If two components name the same destination file, choose one unless the maintainer provides a combined version. To compare a dramatic color grade or night sky, check whether the HUD and light surfaces stay readable during ordinary play. Montage cuts and slow motion make it hard to judge how a preset behaves live.
  4. If a change causes a crash, missing audio or a modified-file error, close FiveM, remove the files that change added and restore the copies you made. Launch again with the restored setup. If you no longer have the original files, use the official support instructions for the affected installation.

FIVEM

Check and compare FiveM sound packs

  1. Check what the archive contains before installing. Files such as RESIDENT.rpf and WEAPONS_PLAYER.rpf are replacement archives. A server audio resource instead comes with a manifest and can declare its own AUDIO_WAVEPACK. Use the maintainer’s instructions for the correct package type and game edition.
  2. Check the server’s rules for client replacements. Where allowed, back up the exact files the maintainer says to replace and try one pack at a time on a private test server. Two packs that replace the same archive can overwrite one another.
  3. Compare the same sound at the same distance and in the same location with your game and system volume unchanged. Listen to both a single sound and a short burst, then check whether voice and ambient sounds stay clear. Recording volume and compression vary between clips, so use the live comparison to judge loudness and distortion.
  4. If sounds go missing, crackle, or the client reports modified files, restore the originals and retest. For a server resource, have the operator check the manifest, dependencies and console.

FIVEM

Deploy a public server recipe with txAdmin

  1. Pick the correct Legacy or Enhanced FXServer build. Start FXServer to open txAdmin, link your Cfx.re account and have your own server registration key ready. On Windows, Enhanced requires the Visual C++ redistributable listed in the Cfx.re setup guide.
  2. Choose a fresh server-data directory. For a basic Cfx.re server, skip database setup. For Qbox, ESX Legacy or QBCore, start MariaDB and have a database connection ready. Qbox requires MariaDB 10.9 or newer and does not support MySQL or XAMPP.
  3. Choose the listed template in Popular Recipes for the Basic Server, Qbox Framework or ESX Legacy. For Qbox Lean or QBCore, open the recipe page, copy the YAML file’s Raw URL and paste it into Remote URL Template. The older QBCore guide shows a Popular Recipes entry that txAdmin has since deprecated.
  4. Review and run the recipe. After the server starts, check the console for resource or database errors and connect to the test server before opening it to players. Keep your own configuration and database backup before replacing an existing installation.

FIVEM

Add a Lua menu to a FiveM resource

  1. Check the menu dependency your script expects. MenuV runs as a standalone resource, the context menu is part of Ox Lib, and qb-menu is common in QBCore setups.
  2. Install the dependency in the server’s resources directory according to its maintainer. Start it before your script and check the server console for missing dependencies.
  3. Connect to your test server and open the menu through the resource that uses it. Check that each option works for the roles that should see it. Enforce permissions for server actions on the server even when the client menu hides the option.

SCOOBY FILES

Config profiles

  1. Match the game, file format and required Scooby version.
  2. Use the game’s config library and its Open Folder or Import control.
  3. Back up your current settings, copy the complete profile, refresh the library and load the config.

Each game has its own supported settings. Use the active game’s folder control to find its profile directory.

SCOOBY FILES

Lua scripts

  1. Check the resource’s download state, game, required Scooby version, host API and Lua runtime.
  2. A listing marked Download pending has no installable download yet. Its source listing and changelog provide context; wait for a matching package before installing.
  3. For an available script, review the package and use the script library’s folder control. Preserve supporting modules and filenames.
  4. Refresh the script library and run the script from that library.

Use your game’s script library folder control and its supported scripting API.

Use a native Scooby script or a compatibility target supplied by your current build. Cherax and Stand scripts require their matching compatibility layer and supported API calls. Check the resource’s requirements; a listed source script may use features outside that layer.

SCOOBY FILES

Translations and languages

  1. Choose a translation catalog that matches your game and Scooby build.
  2. Use the language library’s Open Folder or Import control and copy the full package.
  3. Preserve filenames and supporting files, refresh the library and load the language.

Translation catalogs and layouts must match the host build. Keep any existing custom language overrides.

SCOOBY FILES

Other resource files

  1. Check the resource’s game, required version and included readme.
  2. Use the relevant Open Folder or Import control and preserve the full package’s filenames and supporting folders.
  3. Follow the author’s instructions for that resource type.
