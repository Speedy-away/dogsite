REDM

Install RedM visual effects

  1. Close RedM and extract the effect. Open RedM Application Data and use the destination listed for the download.
  2. For More Blood, place vfxbloodinfo.ymt in citizen/common/data/effects.
  3. For tracer and muzzle effects that supply fxlists.rpf and textures.rpf, put both files from the same preset in citizen/platform/data/effects/ptfx.
  4. Create missing destination folders as needed. Back up matching files before replacing them, then restart RedM.

Effect packs that replace the same files are alternatives. Keep the paired files from each preset together.
