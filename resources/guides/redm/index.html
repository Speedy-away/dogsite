REDM

RSG object streaming files

  1. Download the complete file set supplied with the RSG prop listing, including its model, texture and archetype files.
  2. Place the original YDR, YTD and YTYP files together in a compatible RedM server resource’s stream folder.
  3. Preserve the source resource’s manifest and register stream/prop_weed_ytyp.ytyp using its DLC_ITYP_REQUEST data-file declaration.
  4. Have the server owner start the resource and use the supplied model names after it loads.

These are RedM server assets. Native single-player Scooby RDR2 import compatibility has not been established.

FIVEM / REDM

Server resources and custom assets

  1. Download the resource on Scooby and check the intended runtime, requirements and dependencies. FiveM and RedM use separate resource packages.
  2. If the download is a server resource, give it to the server owner or install it using the included server instructions.
  3. Keep its resource manifest, stream folders and supporting files together. Follow the readme for server configuration and startup order.
  4. For a menu preset, use the menu’s import or Open Folder control instead.

Client preset folders do not install server resources. Access to a server does not grant permission to change its resources.

REDM

Install RedM weapon models and skins

  1. Close RedM and extract the selected skin archive. The weapon packs in this collection provide weapons.rpf.
  2. Open the folder containing your RedM launcher, then open RedM Application Data. Find or create citizen/platform/packs/base/models.
  3. Back up any existing weapons.rpf in that folder, then copy the extracted file there. Restart RedM and check the affected weapon.

The scope packs in this collection also replace weapons.rpf. Use one replacement at a time. Restore your backup to switch back.

REDM

Install RedM sound packs

  1. Close RedM and extract WEAPONS_PLAYER.rpf from the sound pack you chose.
  2. Find the base Red Dead Redemption 2 installation folder containing RDR2.exe. Open x64/audio/sfx inside it.
  3. Save a copy of the original WEAPONS_PLAYER.rpf outside the game folder. Copy in the replacement, then relaunch RedM.

These sound packs all replace the same RDR2 file. Restore the original archive to undo the change.

REDM

Install RedM graphics packs and textures

  1. Close RedM. Open the folder containing your RedM launcher, then open RedM Application Data.
  2. Back up the existing citizen folder. Extract the selected graphics ZIP to a separate folder.
  3. Merge the pack’s citizen folder into RedM Application Data, preserving its paths. Copy the supplied files over their matching paths and leave the rest of the installed citizen folder in place.
  4. Check the pack’s Requirements for Vulkan, DirectX 12 or optional ReShade settings. If the pack includes a DX12 version and you use DX12, follow its instructions for citizen/common/data/visualsettings.dat.
  5. Restart RedM and check the preset. Use one variant at a time when a pack offers different colors or replaces the same files.

To undo the changes, restore the files from your backup and remove any files added by that pack. Check the download’s Requirements for pack-specific folders and dependencies.

For creator-hosted releases such as Hiromasa’s packs, use the version and RedM installation steps on the creator’s release page.

REDM

Install RedM UI presets

  1. Close RedM. In RedM Application Data, open citizen/common/data/ui. Create the ui folder if it is missing.
  2. For a weapon-wheel or color preset, back up any existing colors.xml. Save the chosen preset in this folder as colors.xml.
  3. For UI Boost, back up any existing durations.xml and place the downloaded durations.xml in the same folder.
  4. Restart RedM. If your color preset calls for it, turn off colorblindness mode under Settings → Display.

Choose one colors.xml at a time. UI Boost uses a separate filename and can be installed alongside a color preset.

REDM

Install RedM visual effects

  1. Close RedM and extract the effect. Open RedM Application Data and use the destination listed for the download.
  2. For More Blood, place vfxbloodinfo.ymt in citizen/common/data/effects.
  3. For tracer and muzzle effects that supply fxlists.rpf and textures.rpf, put both files from the same preset in citizen/platform/data/effects/ptfx.
  4. Create missing destination folders as needed. Back up matching files before replacing them, then restart RedM.

Effect packs that replace the same files are alternatives. Keep the paired files from each preset together.

REDM

Apply RedM client settings

  1. Open the listing’s Requirements to identify the file or in-game setting. Close RedM before editing or replacing a file.
  2. For Low Graphics, No Grass, Potato Graphics or resolution changes, back up %APPDATA%/CitizenFX/rdr3_settings/system.xml. Apply the named settings in your existing XML. For Low Graphics, replace only the portion specified in its guide, through the closing </advancedGraphics> tag.
  3. For file-based environment effects, follow the item’s path under RedM Application Data. For example, No Vignette and No Wind use citizen/common/data/timecycle. Back up matching files before merging.
  4. For Weapon Keybinds, use Settings → Controls → Mouse & Keyboard → Key Mapping in the pause menu. Restart after file changes and review the result.

Some downloads are text instructions. Apply the values they list to the named file or menu setting.

SCOOBY FILES

Config profiles

  1. Match the game, file format and required Scooby version.
  2. Use the game’s config library and its Open Folder or Import control.
  3. Back up your current settings, copy the complete profile, refresh the library and load the config.

Each game has its own supported settings. Use the active game’s folder control to find its profile directory.

SCOOBY FILES

Lua scripts

  1. Check the resource’s download state, game, required Scooby version, host API and Lua runtime.
  2. A listing marked Download pending has no installable download yet. Its source listing and changelog provide context; wait for a matching package before installing.
  3. For an available script, review the package and use the script library’s folder control. Preserve supporting modules and filenames.
  4. Refresh the script library and run the script from that library.

Use your game’s script library folder control and its supported scripting API.

Use a native Scooby script or a compatibility target supplied by your current build. Cherax and Stand scripts require their matching compatibility layer and supported API calls. Check the resource’s requirements; a listed source script may use features outside that layer.

SCOOBY FILES

Translations and languages

  1. Choose a translation catalog that matches your game and Scooby build.
  2. Use the language library’s Open Folder or Import control and copy the full package.
  3. Preserve filenames and supporting files, refresh the library and load the language.

Translation catalogs and layouts must match the host build. Keep any existing custom language overrides.

SCOOBY FILES

Other resource files

  1. Check the resource’s game, required version and included readme.
  2. Use the relevant Open Folder or Import control and preserve the full package’s filenames and supporting folders.
  3. Follow the author’s instructions for that resource type.
