COUNTER-STRIKE 2

Players, weapons, knives and equipment

  1. For a package in the in-game repo, open Custom → Repo, search or filter by category, preview it and choose Download and install.
  2. For a downloaded archive, extract the complete resource trees. In Custom → Library, open the category’s gear menu and choose Import folder or Import weapon folder.
  3. Keep compiled models, materials, textures, animations, sounds and icons at their original relative paths. Use Sync to rescan.
  4. Select the model in Library, check the target, team and scope, then select Equip model.

Some library features depend on your Scooby build. For manual installation, close CS2 and copy the resource trees into the game’s game\csgo folder. Use Steam → Manage → Browse local files to find your installation.

COUNTER-STRIKE 2

Custom pet model packs

Open the pack’s details for its model paths, license and supported builds. Keep the models, materials and textures at their original relative paths. Follow the pack’s instructions to install it or generate it from your local CS2 files.

Add or update a pet pack

Put a redistributable pack or a reference to a locally generated pack in project/resource-inbox/cs2/scooby/pets/. Include the creator, source, license and model paths in resource.json. To update a listing, edit the files or metadata in its existing folder.

COUNTER-STRIKE 2

Textures

  1. For image textures, open Custom → Textures → Open folder and copy the PNG, JPG or GIF into C:\scooby\CS2\textures.
  2. Select the image, target and team/weapon scope, preview it, and apply the change.
  3. For a map project, preserve the complete folder and choose Open project on its map-project.json. Check the map, then select Apply opened project.

COUNTER-STRIKE 2

Build a Hammer material from PBR textures

  1. Download the diffuse, OpenGL normal and roughness maps at the same resolution. Place the images in your map addon’s content/csgo_addons/<addon>/materials/ folder.
  2. Launch CS2 Workshop Tools for that addon. Create a .vmat in Material Editor with the Csgo Complex shader. Assign the diffuse map to Color, the OpenGL normal map to Normal, and the roughness map to Roughness. Use separate maps for the individual slots and add ambient occlusion or metalness if the asset supplies them.
  3. Save the material inside the addon. Select it in Hammer’s Asset Browser, apply it to a map surface, then build and test the map.

COUNTER-STRIKE 2

How to use a skybox in Scooby

You’ll need a Scooby CS2 build with VFX sky image import.

  1. Download a 2:1 PNG panorama from the skybox library, such as Ion Nebula, Rose Dawn or Storm Bank.
  2. In Scooby, open VFX, go to the Sky controls and use the image import to select the downloaded .png file.
  3. Look up on a map with a visible sky to see your new skybox.

SCOOBY FILES

Config profiles

  1. Match the game, file format and required Scooby version.
  2. Use the game’s config library and its Open Folder or Import control.
  3. Back up your current settings, copy the complete profile, refresh the library and load the config.

Each game has its own supported settings. Use the active game’s folder control to find its profile directory.

SCOOBY FILES

Lua scripts

  1. Check the resource’s download state, game, required Scooby version, host API and Lua runtime.
  2. A listing marked Download pending has no installable download yet. Its source listing and changelog provide context; wait for a matching package before installing.
  3. For an available script, review the package and use the script library’s folder control. Preserve supporting modules and filenames.
  4. Refresh the script library and run the script from that library.

Use your game’s script library folder control and its supported scripting API.

Use a native Scooby script or a compatibility target supplied by your current build. Cherax and Stand scripts require their matching compatibility layer and supported API calls. Check the resource’s requirements; a listed source script may use features outside that layer.

SCOOBY FILES

Translations and languages

  1. Choose a translation catalog that matches your game and Scooby build.
  2. Use the language library’s Open Folder or Import control and copy the full package.
  3. Preserve filenames and supporting files, refresh the library and load the language.

Translation catalogs and layouts must match the host build. Keep any existing custom language overrides.

SCOOBY FILES

Other resource files

  1. Check the resource’s game, required version and included readme.
  2. Use the relevant Open Folder or Import control and preserve the full package’s filenames and supporting folders.
  3. Follow the author’s instructions for that resource type.
